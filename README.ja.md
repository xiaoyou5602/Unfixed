# Unfixed 🌌

[简体中文](README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | [日本語](README.ja.md)

**人への惹かれ方、気持ち、親密な関係**について考える、インタラクティブな自己探索ガイドです。

誰かを好きになったら、必ず恋人になりたいと思うのでしょうか。誰かと親しくなって日々を分かち合いたくても、その気持ちが友情なのか、恋愛的な惹かれなのか、それとも別の何かなのか、うまく言葉にできないことがあります。関係にどんな名前をつけるかよりも、お互いがどう関わるかのほうが大切なのかもしれません。

Unfixed は5つの視点から自分の気持ちを見つめ、惹かれ方や関係性を表すさまざまな言葉に出会うための場所です。質問に答えながら探索することも、用語集を直接読むこともできます。

**[Unfixed をオンラインで体験](https://unfixed.lumenw.withtoge.us)**（中国本土からもアクセスできます）· [予備リンク](https://unfixed.lumenw.workers.dev)

> 現在、インタラクティブなテストは**簡体字中国語のみ**に対応しています。

## 探索できること

- **恋愛的な惹かれ（romantic attraction）**：恋愛的な気持ちがどのように生まれ、変化するのか。
- **性的な惹かれ（sexual attraction）**：性的な惹かれ、性欲、性に対する態度、性的な関係を持ちたいかどうかを区別する。
- **その他の惹かれ**：プラトニックな惹かれ、感覚的な惹かれ、美的な惹かれ、オルタラスな惹かれ（alterous attraction）など。
- **関係性の好み**：どのような関係を築きたいか、どのような親密さや寄り添い方を望むか。
- **関係の構造と考え方**：排他性、関係を築く相手の人数、優先順位、社会で当然とされがちな関係のあり方をどう捉えるか。

## 用語の出典

用語は AUREA、AVEN、LGBTQIA Wiki などのコミュニティ資料に加え、公開された議論、概念の原典、関連研究を参考にしています。アロマンティック／アセクシュアル（aro/ace）スペクトラム、さまざまな惹かれ方、関係性の形、多様な関係観を扱っています。

一部のマイクロラベルには定義や中国語訳について意見の違いがあり、用語集も引き続き追加・見直しを行っています。具体的な出典、訳語の選び方、要確認項目は[出典付録](appendix-names-and-sources.md)にまとめています。

## 結果の読み方

結果には、各側面で自分の体験に近いかもしれない言葉が示されます。それらを読み比べ、さらに考えるための手がかりとして使ってください。ラベルを使っても、判断を保留しても、まったく使わなくてもかまいません。恋愛的な惹かれと性的な惹かれを区別しにくい場合は、分けずにまとめて回答する選択肢もあります。

質問と結果のマッチング規則は本プロジェクト独自のもので、**心理測定学的な妥当性はまだ検証されていません**。これは自己探索のためのガイドです。

## 使い方

年齢による振り分けは行わず、性経験についても尋ねません。性に関する質問はスキップできます。自分の体験や関係観に関心があれば、事前に用語を知らなくても参加できます。

ローカル版では、各質問への回答記録はブラウザ内に保存されます。

プロジェクトは現在も試験・改善を続けています。質問、結果、用語集へのフィードバックを歓迎します。
