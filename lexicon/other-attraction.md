## Tertiary attraction

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `tertiary-attraction` |
| 英文名 | Tertiary attraction |
| 中文名 | 第三吸引（AUREA 中文版） |
| 别名 | other attraction |
| 层级 | 伞 |
| 上位类 | — |
| 对应的轴 | 维度三整体（3A–3E） |
| 共识度 | 中 |
| 测试适配度 | —（伞本身不作结果，下面的各类吸引分别呈现） |
| 来源 | AUREA 中文吸引与关系术语；已核实 |
| 完成度 | 完整 |

### 通俗释义

> 浪漫与性之外各种吸引的统称，常见的有柏拉图吸引、感官吸引、审美吸引和别样吸引

### 核心特征

- 讲的是浪漫、性之外的吸引：想和某人做朋友（柏拉图），想和某人有拥抱、牵手这类非性的接触（感官），欣赏某人的外貌（审美），以及说不清是友情还是爱情、但很想靠近的感觉（别样）
- 这些吸引可以单独出现，也可以和浪漫、性吸引同时出现
- 有没有这些吸引，不决定一个人在不在 aro-spec 或 ace-spec 里
- 把它们分开说，是为了不把它们误当成浪漫或性吸引，也不反过来

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 浪漫吸引 | 浪漫吸引是想和某人建立浪漫关系、进行浪漫互动；第三吸引里的各种感觉都不以此为目标。两者可以同时存在 |
| 性吸引 | 性吸引是想和某人发生性接触；感官吸引想要的是非性的接触（拥抱、牵手），审美吸引只是欣赏外貌 |
| 4B 关系元素 | 关系元素讲的是想在关系里放进什么（同居、拥抱等），不指向特定的人；第三吸引是对某个具体的人产生的感觉 |
| Queerplatonic attraction | 有人把它算作第三吸引的一种，也有人认为它属于关系偏好，不是独立的吸引类型 |

**常见误解**

- **"觉得一个人好看，就是喜欢上了 ta。"** 欣赏外貌是审美吸引，它可以和浪漫、性吸引一起出现，也可以单独出现。
- **"想抱一个人，就是有性方面的想法。"** 想要非性的身体接触是感官吸引，和性吸引分开。
- **"aro 或 ace 的人没有这些吸引。"** 第三吸引和是否在光谱内无关，光谱内外的人都可能有，也都可能没有。
- **"lush 就是感官吸引的心动。"** AUREA 这样用，也有来源把它解释为以性为主的强烈吸引；含义有分歧，题目和结果里不用这个词。

### 社区定义

aro 社群用这个词把"浪漫""性"之外的吸引放在一起讲。这个测试收了柏拉图、感官、审美、别样四类，情感吸引、酷儿柏拉图吸引放在别样吸引旁边作为细分，智性吸引作为可选项。"第三"只表示它们排在浪漫、性之后提起，不表示它们更不重要。

这些吸引本身不决定一个人在不在 aro-spec 或 ace-spec 里。

## Platonic attraction

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `platonic-attraction` |
| 英文名 | Platonic attraction |
| 中文名 | 柏拉图吸引（通行） |
| 别名 | 对应的心动俗称：squish |
| 层级 | 节点 |
| 上位类 | Tertiary attraction |
| 对应的轴 | 3A |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | AUREA 中文吸引与关系术语 |
| 完成度 | 完整 |

### 通俗释义

> 对某个特定的人产生想成为朋友、变得更亲近的渴望，想和 ta 进入一段亲密的朋友关系。这种吸引通常与浪漫、性无关，但每个人期待的关系可以不同。

### 核心特征

- 指向某个具体的人：不是"想交朋友"这种一般愿望，而是对某个人产生想亲近的渴望
- 想要的是朋友式的亲近：想和 ta 成为朋友、更亲近，或进入一段亲密的朋友关系
- 这种亲近通常不以浪漫或性为目标，但每个人期待的关系可以不同
- 可以和浪漫、性、感官、审美等其他吸引同时存在，一种吸引不取消另一种

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 浪漫吸引 | 两者都可能表现为"想和这个人更亲近"。区别在于想要的关系：柏拉图吸引想要朋友式的亲近，浪漫吸引想要恋爱式的亲近或互动。分不清时，把它当成介于两者之间或两者都不是，也是可以的 |
| 感官吸引 | 柏拉图吸引想要的是朋友关系和亲近感；感官吸引想要的是拥抱、依偎、牵手这类非性的身体接触。两者可以同时出现 |
| 审美吸引 | 审美吸引是欣赏对方的外貌或美感，不一定想和对方更亲近；柏拉图吸引的核心是想成为朋友、更亲近 |
| 酷儿柏拉图吸引 | 酷儿柏拉图吸引想建立的是超出常规友谊、但不以浪漫为核心的 QPR；柏拉图吸引通常指向朋友关系。两者边界因人而异，有人会把它们放在一起用 |
| Aplatonic | 柏拉图吸引是对某个人产生的渴望；aplatonic 指这种渴望很少或几乎不出现 |

**常见误解**

- **"想和某个人做朋友，就是柏拉图吸引。"** 它指的是对某个具体的人产生想成为朋友、更亲近的渴望；一般的社交愿望，或者现在有没有朋友，是另一回事。
- **"柏拉图吸引就是纯粹的友情。"** 它是一种吸引，描述想和某个人建立朋友式的亲近；有这种吸引的人也可以同时有浪漫或性吸引。
- **"有柏拉图吸引就一定想谈恋爱。"** 它想要的是朋友式的亲近，不要求恋爱。
- **"柏拉图吸引和感官吸引只能有一个。"** 两者讲的是不同的渴望，可以同时存在。

## Aplatonic

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `aplatonic` |
| 英文名 | Aplatonic |
| 中文名 | 无柏拉图吸引（AUREA 中文版） |
| 别名 | — |
| 层级 | 节点（身份性结果，延伸区） |
| 上位类 | Platonic attraction |
| 对应的轴 | 3A × ② 频率与强度 |
| 共识度 | 中 |
| 测试适配度 | C |
| 来源 | AUREA 中文吸引与关系术语；已核实 |
| 完成度 | 完整 |

### 通俗释义

> 很少或几乎不体验柏拉图吸引，也就是很少对某个特定的人产生想成为朋友、变得更亲近的渴望。它不等于讨厌别人、不想社交，也不代表没有朋友。

### 核心特征

- 讲的是柏拉图吸引：对某个具体的人有没有"想和 ta 做朋友、更亲近"的渴望
- 这种渴望很少出现，或几乎不出现
- 和社交意愿、交友能力、现在有没有朋友是不同的事
- 是 aro 社群延伸区里的一种身份说法，用不用由本人决定

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 柏拉图吸引 | 描述对某个人的朋友式渴望；aplatonic 描述这种渴望很少或几乎不出现 |
| 内向、不喜欢社交 | 内向或不想社交讲的是社交意愿和精力；aplatonic 讲的是对具体对象的柏拉图吸引。两者可以同时出现，也可以互不相干 |
| 无浪漫倾向 / 无性恋 | 分别讲浪漫吸引和性吸引；aplatonic 讲柏拉图吸引。三者可以同时存在，也可以只符合其中一个 |
| 当前没有朋友 | 有没有朋友是关系和现状；aplatonic 讲的是吸引。没有朋友的人不一定 aplatonic，aplatonic 的人也可能有很亲近的朋友 |

**常见误解**

- **"aplatonic 就是讨厌人、不需要朋友。"** 它描述的是柏拉图吸引很少或几乎不出现，不等于讨厌别人，也不等于没有朋友。
- **"不想社交就是 aplatonic。"** 不想社交、喜欢独处和缺少柏拉图吸引是两件事。
- **"aplatonic 一定也是 aro 或 ace。"** 三种说法讲不同的吸引，可以同时出现，也可以只符合其中一个。
- **"这只是心理或身体出了问题。"** 这个词只描述柏拉图吸引的多寡，不说明原因，也不判断一个人的社交能力或心理状态。

## Sensual attraction

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `sensual-attraction` |
| 英文名 | Sensual attraction |
| 中文名 | 感官吸引（通行） |
| 别名 | 对应的心动俗称：lush（含义有分歧，题目和结果里不用） |
| 层级 | 节点 |
| 上位类 | Tertiary attraction |
| 对应的轴 | 3B |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | AUREA 中文吸引与关系术语 |
| 完成度 | 完整 |

### 通俗释义

> 想和某个特定的人有拥抱、依偎、牵手这类非性的身体接触，或想靠近对方。它和性吸引、一般的身体接触需求是不同的事。

### 核心特征

- 指向某个具体的人：不是"想被抱"这种一般的身体需求，而是对某个人产生的渴望
- 想要的是非性的身体接触或靠近，比如拥抱、依偎、牵手
- 和性吸引分开：感官吸引想要的不一定是性接触
- 可以和浪漫、性、柏拉图、审美等其他吸引同时存在

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 性吸引 | 性吸引想要的是和对方发生性接触；感官吸引想要的是拥抱、依偎、牵手这类非性接触。两者可以同时出现，也可以只有其中一种 |
| 柏拉图吸引 | 柏拉图吸引想要的是朋友式的亲近；感官吸引想要的是身体接触或靠近。两者可以同时出现 |
| 性欲、生理唤起 | 性欲和生理唤起是身体层面的状态；感官吸引是对某个具体的人产生的接触渴望 |
| 一般触碰需求 | 想被拥抱、想有身体接触，但没有指向某个具体的人，不属于感官吸引；感官吸引的核心是对某个特定对象的渴望 |

**常见误解**

- **"想抱一个人，就是有性方面的想法。"** 想要非性的拥抱、依偎是感官吸引，和性吸引是两件事。
- **"感官吸引一定伴随浪漫吸引。"** 它可以单独出现，也可以和浪漫吸引同时出现。
- **"想要身体接触就是缺爱或寂寞。"** 这个词只描述想和某个人有非性接触，不说明原因。
- **"lush 就是感官吸引的固定叫法。"** 有人这样用，也有人用它指以性为主的强烈吸引；含义不统一。

### 社区定义

AUREA 把它定义为用与性无关的方式（比如拥抱、依偎）与特定对象接触或靠近的兴趣或渴望。社群把这种心动叫 lush；这个词也有人用来指以性为主的强烈吸引，含义有分歧。

## Asensual

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `asensual` |
| 英文名 | Asensual |
| 中文名 | 无感官吸引（拟） |
| 别名 | — |
| 层级 | 节点（身份性结果） |
| 上位类 | Sensual attraction |
| 对应的轴 | 3B × ② 频率与强度 |
| 共识度 | 低 |
| 测试适配度 | B |
| 来源 | 逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 很少或几乎不体验感官吸引，也就是很少想和某个特定的人有拥抱、依偎、牵手这类非性的身体接触。它和是否喜欢被触碰、是否有性吸引是不同的事。

### 核心特征

- 讲的是感官吸引：对某个具体的人有没有想有非性身体接触的渴望
- 这种渴望很少出现，或几乎不出现
- 和性吸引、性欲、对一般触碰的态度是不同的事
- 是感官侧的一种身份说法，用不用由本人决定

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 感官吸引 | 描述对某个人的非性接触渴望；asensual 描述这种渴望很少或几乎不出现 |
| 无性恋 | 无性恋讲性吸引；asensual 讲感官吸引。一个人可以只有其中一种，也可以两种都有或都没有 |
| 排斥触碰、触觉敏感 | 这些讲的是对触碰的态度或身体反应；asensual 讲的是对特定对象的渴望少，不代表讨厌触碰 |
| 一般触碰需求 | 不指向特定对象的触碰需求是另一回事，不属于感官吸引 |
| 当前没有亲密接触 | 有没有拥抱、牵手是经历和现状；asensual 讲的是吸引本身 |

**常见误解**

- **"asensual 就是讨厌拥抱、不想被人碰。"** 它描述的是对特定对象的感官吸引很少或几乎不出现；对触碰本身的态度可以喜欢、无所谓或排斥。
- **"asensual 就是无性恋。"** 两者讲不同的吸引，可以同时出现，也可以只符合其中一个。
- **"这是因为没有对象或没有经验。"** 经历不决定有没有这种吸引；现在有没有亲密接触，和 asensual 是两件事。
- **"这是身体有问题。"** 这个词只描述感官吸引的多寡，不说明原因。

### 社区定义

这个词按"感官吸引很少或几乎不出现"来用。中文名"无感官吸引"是拟名；不同人对它的理解可能不完全一样，用不用由本人决定。

## Aesthetic attraction

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `aesthetic-attraction` |
| 英文名 | Aesthetic attraction |
| 中文名 | 审美吸引（通行） |
| 别名 | 对应的心动俗称：swish |
| 层级 | 节点 |
| 上位类 | Tertiary attraction |
| 对应的轴 | 3C |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | AUREA 中文吸引与关系术语 |
| 完成度 | 完整 |

### 通俗释义

> 被某个特定的人的外貌、气质或整体美感吸引，想多看几眼、欣赏对方。这种欣赏本身不要求进一步发展，也不等于想恋爱或有性接触。

### 核心特征

- 指向某个具体的人，被吸引的是 ta 的外貌、气质或整体的美感
- 核心是欣赏和想多看，不一定想和对方建立关系
- 不要求有浪漫、性、柏拉图或感官方面的兴趣
- 可以和其他吸引同时出现，一种吸引不取消另一种

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 浪漫吸引 | 浪漫吸引包含想和对方恋爱、进行浪漫互动的渴望；审美吸引只是欣赏对方的外在，不要求更进一步。两者可以同时出现 |
| 性吸引 | 性吸引想要的是性接触；审美吸引是对外貌或美感的欣赏，不包含这种渴望 |
| 生理唤起 | 生理唤起是身体层面的反应；审美吸引是欣赏，不等于被唤起 |
| 柏拉图吸引 | 柏拉图吸引想和对方成为朋友、更亲近；审美吸引可以只是看看、欣赏，不一定想靠近 |

**常见误解**

- **"觉得一个人好看，就是喜欢上了 ta。"** 欣赏外貌是审美吸引，它可以单独存在，也可以和浪漫或性吸引同时出现；觉得好看本身不说明想恋爱或有性方面的想法。
- **"审美吸引一定会发展成浪漫或性吸引。"** 不一定；它可以只停在欣赏。
- **"审美吸引只和外貌有关。"** 被吸引的可以是外貌、气质或整体的美感，不同人说的重点不一样。
- **"审美吸引不算真正的吸引。"** 社群把它单独列为一种吸引；它可能不指向任何关系，但仍然是真实存在的感受。

## Alterous attraction

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `alterous-attraction` |
| 英文名 | Alterous attraction |
| 中文名 | 别样吸引（AUREA 中文版） |
| 别名 | 对应的心动俗称：mesh |
| 层级 | 节点 |
| 上位类 | Tertiary attraction |
| 对应的轴 | 3D |
| 共识度 | 中 |
| 测试适配度 | B |
| 来源 | AUREA 中文吸引与关系术语；已核实 |
| 完成度 | 完整 |

### 通俗释义

> 对某个特定的人产生想亲近、想要情感连接的兴趣或渴望，但这种感觉不完全像恋爱，也不完全像朋友；它可以在两者之间，也可以不在这套分类里。

### 核心特征

- 指向某个具体的人
- 想要的是亲密的情感连接或靠近
- 这种感觉不完全符合"恋爱"，也不完全符合"朋友"；有时介于两者之间，有时两者都不是
- 可以和浪漫、性、柏拉图、情感等其他吸引同时存在，不要求二选一

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 浪漫吸引 | 两者都可能有很强的情感投入。浪漫吸引通常包含想和对方恋爱或沿恋爱脚本发展的成分；别样吸引不要求这些，也不完全属于恋爱。分不清时，"介于两者之间"或"两者都不是"也是可以的 |
| 柏拉图吸引 | 柏拉图吸引通常指向朋友式的亲近；别样吸引的亲近感不完全落在朋友这一边 |
| 情感吸引 | 情感吸引强调想建立深层的情感连接；别样吸引强调这种亲近不完全适合用浪漫或朋友来描述。两者有重叠，可以同时有 |
| 酷儿柏拉图吸引 | 酷儿柏拉图吸引想建立的是 QPR；别样吸引描述的是一种感觉。基于别样吸引的关系通常也叫 QPR，但两者不是同一个词 |
| 困惑（quoi） | quoi 描述的是很难分类，或觉得这套分类不适用；别样吸引描述的是那种确实存在、但不完全落在浪漫或朋友里的亲近感。两者可以同时出现，不要求先分清再用 |

**常见误解**

- **"别样吸引就是不敢承认的恋爱。"** 它是一种自己成立的亲近感，不要求沿恋爱脚本发展；想不想恋爱，要另外看。
- **"别样吸引就是'友情以上，恋爱未满'。"** 它可以在两者之间，也可以完全在浪漫和朋友的分类之外，"友情以上"只是其中一种说法。
- **"有别样吸引就一定要建立 QPR。"** 吸引是一种感觉，QPR 是一种关系形态；要不要建立、建立成什么样，由当事人决定。
- **"别样吸引和情感吸引只能选一个。"** 两者有一部分重叠，可以同时有。

## Emotional attraction

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `emotional-attraction` |
| 英文名 | Emotional attraction |
| 中文名 | 情感吸引 |
| 别名 | 有人视为与 alterous attraction 同义 |
| 层级 | 节点 |
| 上位类 | Tertiary attraction |
| 对应的轴 | 3D |
| 共识度 | 中 |
| 测试适配度 | B |
| 来源 | 逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 想和某个特定的人建立很深的情感连接，比如彼此理解、能倾诉、互相支持。这种感觉不一定是恋爱式的，有人把它和别样吸引当成同一回事。

### 核心特征

- 指向某个具体的人
- 想要的是情感上的靠近：被理解、能倾诉、彼此支持
- 这种连接不一定是恋爱式的，也不一定以成为朋友为目标
- 和别样吸引有一部分重叠，有人当成同义词，也有人分开用

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 别样吸引 | 两者都强调情感上的亲近。别样吸引更强调这种亲近不完全属于浪漫或朋友；情感吸引更强调深层的情感连接。有人把两者当成同义词，也有人分开用 |
| 柏拉图吸引 | 柏拉图吸引想和对方成为朋友、更亲近；情感吸引想建立的是深层的情感连接，不一定要以朋友关系为目标。两者可以同时出现 |
| 浪漫吸引 | 浪漫吸引通常包含恋爱式的互动或关系期待；情感吸引不要求这些 |
| 一般的情感支持需求 | 想被理解、想有人倾诉，如果没有指向某个具体的人，就不属于这里说的情感吸引；情感吸引的核心是对某个人的渴望 |

**常见误解**

- **"情感吸引就是恋爱。"** 它不要求恋爱，也不一定想成为恋人。
- **"想被理解、想倾诉就是情感吸引。"** 要看这种感觉是不是指向某个具体的人、想和 ta 建立深层连接；一般的倾诉需求是另一回事。
- **"情感吸引和别样吸引只能选一个。"** 两者有重叠，可以同时有，也有人把它们当成同一个意思。
- **"有情感吸引就一定有身体接触的渴望。"** 情感吸引讲的是情感连接，身体接触的渴望属于感官吸引，两者可以分开。

### 社区定义

这个说法在社群里的用法不完全一致：有人把它和别样吸引当成同义，也有人用它专指想和某个特定的人建立很深的情感连接。它通常指理解、倾诉、支持这类情感上的亲近，不要求恋爱或身体接触。

## Queerplatonic attraction

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `queerplatonic-attraction` |
| 英文名 | Queerplatonic attraction |
| 中文名 | 酷儿柏拉图吸引 |
| 别名 | — |
| 层级 | 节点 |
| 上位类 | Tertiary attraction（也有人认为属于关系偏好） |
| 对应的轴 | 3D |
| 共识度 | 中 |
| 测试适配度 | B |
| 来源 | 逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 想和某个特定的人建立酷儿柏拉图关系（QPR）的渴望。QPR 是一种可以很亲近、很重要、有承诺，但不以浪漫为核心的关系；具体内容由当事人商量。

### 核心特征

- 指向某个具体的人
- 想要的关系是 QPR：可以比常规友谊更亲近、更重要，但不以浪漫为核心
- 关系里放什么（同居、拥抱、承诺、排他等）由当事人商量，没有固定模板
- 有人把它算作一种吸引，也有人认为它更像关系偏好

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| QPR | QPR 是一段关系，酷儿柏拉图吸引是对某个人的渴望。有这种吸引的人不一定真的建立了 QPR；有 QPR 的人也不一定用这个词描述自己的吸引 |
| 柏拉图吸引 | 柏拉图吸引通常指向朋友式的亲近；酷儿柏拉图吸引指向的是超出常规友谊、但不以浪漫为核心的 QPR。两者可能不容易分清，取决于想要的关系是什么样 |
| 别样吸引 | 别样吸引描述的是不完全属于浪漫或朋友的亲近感；酷儿柏拉图吸引明确指向想建立 QPR。基于别样吸引的关系通常也叫 QPR，两者有重叠 |
| 浪漫吸引 | 浪漫吸引想要的是恋爱式的关系；酷儿柏拉图吸引想要的关系不以浪漫为核心 |
| 关系偏好 | 有人把酷儿柏拉图吸引看成关系偏好而不是独立的吸引类型；这个词的归类没有完全统一的说法 |

**常见误解**

- **"酷儿柏拉图吸引就是没有性的恋爱。"** QPR 不以浪漫为核心，和有没有性无关：有的 QPR 包含性，有的不包括；恋爱也可以没有性。
- **"有这种吸引就一定想同居、想排他。"** 关系内容由当事人商量，可以有也可以没有。
- **"酷儿柏拉图吸引只属于 aro 或 ace。"** 它起源于 aro 和 ace 社群，但任何想要这种关系的人都可以用。
- **"有这种吸引就必须把关系叫 QPR。"** 用不用这个词由当事人决定。

### 社区定义

社群对它的归类有分歧：有人把它算作第三吸引的一种，也有人认为它属于关系偏好，而不是独立的吸引类型。它描述的是想和某个特定对象建立 QPR 的渴望，不是 QPR 本身。

### 通俗释义

> 被某个特定的人的想法、谈吐、见识或思考方式吸引。它讲的是被对方怎么想、怎么表达所吸引，而不是外貌或身体接触。

### 核心特征

- 指向某个具体的人
- 被吸引的是 ta 的想法、谈吐、见识或思考方式
- 可以和浪漫、性、审美、柏拉图等其他吸引同时存在

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 审美吸引 | 审美吸引被对方的外貌、气质或美感吸引；智性吸引被对方的想法和表达吸引 |
| 柏拉图吸引 | 柏拉图吸引想和对方成为朋友、更亲近；智性吸引是被对方怎么想、怎么说吸引。两者可以同时出现 |
| 浪漫吸引 | 被一个人的想法打动，可以和浪漫吸引同时出现，但不是同一件事；智性吸引本身不要求恋爱 |
| 觉得一个人聪明、专业 | 觉得对方聪明或有能力，可能只是评价；智性吸引描述的是被这个人的思想、谈吐吸引 |

**常见误解**

- **"觉得对方聪明，就是智性吸引。"** 觉得聪明可以只是评价；智性吸引是被 ta 的想法、谈吐或思考方式吸引。
- **"智性吸引一定会变成恋爱。"** 它可以单独存在，不要求恋爱。
- **"智性吸引不算真正的吸引。"** 它描述的是被一个人的思想和表达吸引，和浪漫、性、审美等吸引是不同的事。
- **"有智性吸引就一定有身体接触的渴望。"** 智性吸引讲的是思想和表达，身体接触属于其他吸引。
