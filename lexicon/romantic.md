## Aro-spec

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `aro-spec` |
| 英文名 | Aro-spec |
| 中文名 | 无浪漫光谱（拟） |
| 别名 | aromantic spectrum、arospec；口语里也常简称 aro |
| 层级 | 伞 |
| 上位类 | Aspec |
| 对应的轴 | 浪漫侧的 ①–⑨ 整体 |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | AUREA 英文完整术语表、AUREA 中文基本术语；中文名为本稿拟名 |
| 完成度 | 完整 |

### 通俗释义

> 很少或不体验浪漫吸引、以有条件或非典型方式体验、与"浪漫吸引"这个概念关系复杂，或体验与社会对"浪漫爱"的主流期待不一致的人

### 核心特征

- 讲的是浪漫吸引：会不会对某个人产生想"在一起"、成为一对的那种感觉
- 这种感觉在自己身上不按常见的方式出现：很少、很淡、要特定条件、来去不定，或者说不清什么才算浪漫
- 它是一片范围，下面有很多更具体的词；用不用、用哪个，由本人决定

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Aromantic | aromantic 是伞下的一个点，指很少或从不体验浪漫吸引；aro-spec 是整片范围。口语里 "aro" 两种意思都有人用，要看上下文 |
| Greyromantic | grey 是伞下"介于中间"的那一段，本身也是一把小伞；aro-spec 还包括 aromantic 和 quoi 一支 |
| Ace-spec | ace-spec 讲的是性吸引。浪漫和性可以分开看：aro-spec 的人可以有性吸引（alloaro），也可以没有（aroace） |
| Aspec | aspec 是更大的总伞，包含 aro-spec 和 ace-spec |
| 不寻求伴侣式关系（主动单身） | 不想谈恋爱是意愿，不是吸引。有人有浪漫吸引但不想恋爱，并不因此在 aro-spec 内；也有 aro-spec 的人想要浪漫关系（cupioromantic） |

**常见误解**

- **"aro 就是冷漠、没感情。"** aro-spec 讲的只是浪漫吸引。很多人对朋友、家人、伴侣有很深的感情，也很需要亲密关系。
- **"只是还没遇到对的人。"** 这把取向当成一个等着被解决的问题。社群的立场是：这是一种体验方式，不是缺了什么；年纪大了、遇到某个人以后才发现自己有浪漫吸引的情况也存在，但那是本人的发现，不是旁人可以预言的。
- **"aro 一定讨厌恋爱。"** 有没有吸引和喜不喜欢浪漫是两件事。有人对自己卷入浪漫很排斥，也有人享受浪漫活动、想要浪漫关系（见 3.5 的浪漫态度）。
- **"aro 不需要亲密关系。"** 很多 aro-spec 的人想要 QPR、承诺式友谊或选择的家人，只是不以浪漫为核心。
- **"命中了某个对象类型或举动偏好，就是 aro-spec。"** fictoromantic、autoromantic、placioromantic 这类词描述的是吸引指向谁、想怎样表达，光谱内外的人都可能用，不单独决定归属。

### 社区定义

aromantic、greyromantic、demiromantic、quoiromantic 等都在 aro-spec 这把伞下面。伞的范围有宽有窄：窄的只算很少或有条件地体验浪漫吸引的人，宽的把和"浪漫吸引"这个概念关系复杂的人也算进来，quoiromantic 就是因为这一层才在伞下。这个测试用宽的范围。

一个人是不是 aro-spec，最终由本人认同决定。

## Aromantic

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `aromantic` |
| 英文名 | Aromantic |
| 中文名 | 无浪漫倾向（通行） |
| 别名 | aro（也常用来泛指整个 aro-spec） |
| 层级 | 节点 |
| 上位类 | Aro-spec |
| 对应的轴 | ② 频率与强度 |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | 主树通用词；定义取自 02 第 3.4 节，逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 很少或从不体验浪漫吸引的人。浪漫吸引指想和某个特定的人建立浪漫关系、进行浪漫互动的渴望。这不代表冷漠，也不等于不想要亲密关系。

### 核心特征

- 想和某个人"在一起"、成为一对的那种渴望，很少出现，或从来没有出现过
- 对朋友、家人或伴侣，仍然可以有很深的感情，这和浪漫吸引是分开的
- 是否想要亲密关系，要另外看，不由有没有浪漫吸引决定

### 体验举例

- 朋友聊起暗恋的心情，你能听懂，也愿意陪着聊，但自己很少有那种想"在一起"的心动。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Aro-spec | 整片范围，aromantic 是其中一个点 |
| Greyromantic | 介于 aromantic 与 alloromantic 之间的那一段：很少、很弱，或只在特定情况下才有 |
| Cupioromantic | 同样很少有浪漫吸引，但希望拥有一段浪漫关系；aromantic 只说吸引，不说想不想要关系 |
| Apothiromantic | 在 aromantic 的基础上，还对自己卷入浪漫感到排斥 |

**常见误解**

- **"aromantic 一定不想恋爱。"** 有没有浪漫吸引，和想不想要浪漫关系是两件事。有的人没有浪漫吸引，却仍想要一段浪漫关系（见 Cupioromantic）。

### 社区定义

口语里常只说 "aro"，有时指 aromantic 本身，有时指整个 aro-spec，要看上下文。

## Greyromantic

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `greyromantic` |
| 英文名 | Greyromantic |
| 中文名 | 灰色浪漫倾向（通行；也说"灰浪漫"） |
| 别名 | grey-aromantic、grey-aro |
| 层级 | 伞/节点 |
| 上位类 | Aro-spec |
| 对应的轴 | ② 频率与强度；① 分类方式（有点模糊） |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | 主树通用词；定义取自 02 第 3.4 节，逐条来源待补；核心特征取自社群图文 |
| 完成度 | 完整 |

### 通俗释义

> 很少体验浪漫吸引、体验很弱、只在特定情况下才有，或不确定自己的感受算不算浪漫吸引的体验。它介于 aromantic 与 alloromantic 之间，下面还有几个更具体的说法。

### 核心特征

- 浪漫吸引确实有，但频率极低，可能几年甚至十几年才有一次，或感觉很弱，不像大多数人那样稳定
- 感觉可能非常微弱，不足以驱动去建立一段正式的恋爱关系
- 吸引力可能不稳定，时有时无，或在特定条件下突然产生，又突然消失
- 边界模糊：往往难以区分柏拉图式的深厚友情和浪漫爱情，对"这算不算浪漫吸引"常常拿不准，因此感到困惑

### 体验举例

- 偶尔对某个人有过想靠近、想拥有一段特别关系的念头，却说不清那是不是浪漫吸引。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Aromantic | 完全没有，或几乎从不有；grey 是"很少、很弱，或拿不准"的中间地带 |
| Demiromantic | grey 底下的一个子类，只在与某人建立深厚情感连接之后，才可能有浪漫吸引 |
| Alloromantic | 会体验浪漫吸引，而且方式不在 aro-spec 之内；grey 则仍在 aro-spec 之内 |
| Quoiromantic | 两者都可能拿不准；grey 讲的是体验本身很弱或有条件，quoi 讲的是分不清或觉得概念不适用 |

**常见误解**

- **"grey 就是 aro 和 allo 各占一半。"** grey 是一片有自己体验方式的范围，不是两端的平均。
- **"grey 就是还没想清楚。"** 有的人很确定自己属于 grey，这不代表还没想清楚。

### 社区定义

社群里对 grey 的范围有宽、窄两种说法。窄的只包括很少、很弱地体验浪漫吸引的人；宽的还包括只在特定条件下有、或拿不准自己算不算的人。这个测试用宽的说法，与 Aro-spec 的社区定义一致。

## Demiromantic

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `demiromantic` |
| 英文名 | Demiromantic |
| 中文名 | 半浪漫倾向（通行） |
| 别名 | — |
| 层级 | 子类（条件型） |
| 上位类 | Greyromantic |
| 对应的轴 | ③ 触发条件 |
| 共识度 | 高 |
| 测试适配度 | B |
| 来源 | 主树通用词；定义取自 02 第 3.4 节，逐条来源待补；误解取自社群图文 |
| 完成度 | 完整 |

### 通俗释义

> 只有在与某人建立深厚的情感连接之后，才可能对其产生浪漫吸引的体验。连接是浪漫吸引出现的前提，但有了连接，不一定就会有浪漫吸引。

### 核心特征

- 浪漫吸引不会直接从初见或外表产生，要先有深厚的情感连接
- 连接是必要条件，不是保证：有了连接，也不一定会对这个人产生浪漫吸引
- 什么样的连接才算深厚，由本人判断
- 恋爱关系几乎都是从“好朋友”转化而来的，但即使是朋友，也不是谁都可以；开启心动的门槛很高

### 体验举例

- 和一位相处久了、彼此很信任的朋友，慢慢才有了浪漫的心动；在那之前，就算对方很出色，也不会让你心动。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Greyromantic | 大伞。demi 是它底下的一个条件型子类 |
| Recipromantic | 前提是对方对自己有意；demi 的前提是情感连接 |
| Frayromantic | 方向相反：fray 的吸引在不熟悉时出现，随了解加深而减弱；demi 要熟了才有 |

**常见误解**

- **"demi 就是慢热。"** 慢热说的是一个人不急着表达或推进关系；demi 说的是浪漫吸引本身需要先有连接才会出现。
- **"他们只是眼光太高，太挑剔。"** 不是，是生理机制决定了“开关”还没打开。在羁绊形成前，对方即使是男神或女神，他们也只是欣赏，没有恋爱的欲望。
- **"这不就是所有人谈恋爱的过程吗？"** 不是。大多数人可以在不了解对方深层性格的情况下，就先产生好感和追求的欲望，然后通过接触去了解；而半浪漫倾向者是必须先了解、先有羁绊，才有好感。
- **"这不就是传统保守吗？"** 不是。这不是道德选择，而是一种天生的取向。

### 社区定义

有的人把 demi 视为 grey 的子类，也有人把它当成与 grey 并列的独立身份，两种说法都有人使用。

## Recipromantic

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `recipromantic` |
| 英文名 | Recipromantic |
| 中文名 | 互惠浪漫倾向（社群流传） |
| 别名 | — |
| 层级 | 子类（条件型） |
| 上位类 | Greyromantic |
| 对应的轴 | ③ 触发条件 |
| 共识度 | 中 |
| 测试适配度 | B |
| 来源 | 主树通用词；定义取自 02 第 3.4 节，逐条来源待补；误解取自社群图文 |
| 完成度 | 完整 |

### 通俗释义

> 只有在知道对方对自己有浪漫兴趣之后，才会对对方产生浪漫吸引的体验。对方先表达了心意，才是吸引出现的前提。

### 核心特征

- 浪漫吸引要等到知道，或强烈感觉到对方对自己有浪漫兴趣之后，才会出现
- 在那之前，即使相处愉快、彼此很熟，也不会有浪漫吸引
- 这种体验的重点在于"知道对方有意"这一步；知道之后，吸引可能很快出现，甚至很强烈，但强弱因人而异

### 体验举例

- 一位朋友表白之前，你从没把对方往恋人那边想；知道对方的心意后，才第一次觉得对方有些不一样。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Demiromantic | 同属 grey 的条件型子类。demi 的前提是深厚的情感连接，recip 的前提是知道对方有意 |
| Akoiromantic | akoi 讲的是有了吸引之后，对回应的需要，或不希望被回应；recip 讲的是对方先有心意，自己才有吸引 |

**常见误解**

- **"只是慢热，或需要安全感。"** 不是。有人会说“我要先确定对方喜欢我，才敢喜欢”，但 Recipromantic 的人不是不敢表达，而是真的没有心动，直到对方先心动，自己才开始心动。慢热的人在知道对方的心意之前，还是会有单向的 Crush 体验。
- **"只是喜欢追自己的人，享受被追求的感觉。"** 不是。重点不在享受被追的过程，而是浪漫吸引必须以对方的吸引为前提。就算对方追得很猛，如果自己没有产生浪漫吸引，也还是不会喜欢。

## Frayromantic

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `frayromantic` |
| 英文名 | Frayromantic |
| 中文名 | 磨损浪漫倾向（社群流传） |
| 别名 | — |
| 层级 | 子类（条件型） |
| 上位类 | Greyromantic |
| 对应的轴 | ③ 触发条件 |
| 共识度 | 中 |
| 测试适配度 | B |
| 来源 | 主树通用词；定义取自 02 第 3.4 节，逐条来源待补；误解取自社群图文 |
| 完成度 | 完整 |

### 通俗释义

> 浪漫吸引只出现在还不太熟悉的阶段，随着了解加深而减弱或消失的体验。它和 demi 的方向相反。

### 核心特征

- 浪漫吸引多半出现在还不太熟悉的阶段
- 随着相处和了解加深，这份吸引会逐渐减弱，甚至消失
- 这种“下头”不是因为发现对方的缺点，而是因为“太熟了”：对方越敞开心扉，浪漫感觉反而越流失
- 渴望恋爱，但很难在长期关系中维持浪漫吸引力；这不代表不能维持关系，只是浪漫的感觉会变

### 体验举例

- 刚认识一个人时心里很有悸动，相处久了，那份悸动慢慢变成了平常的亲近。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Demiromantic | 方向相反：demi 要先有深厚连接才有吸引，fray 则是熟了之后吸引会变淡 |
| Aroflux | 两者都会随时间变化；fray 的变化跟着熟悉程度走，aroflux 讲的是浪漫吸引的强弱在有与无之间起伏 |

**常见误解**

- **"fray 就是怕承诺，或是追求新鲜感。"** 这份吸引随熟悉度变化，是一种体验模式；它不等于害怕承诺，也不等于新鲜感过去。
- **"那不就没办法维持长期关系？"** 可以。只要双方都理解并接受这种模式，就能维持长期关系；有些磨损浪漫倾向者会选择建立酷儿柏拉图关系（QPR），用深厚的亲情和承诺来维持一段长久的关系。

## Akoiromantic

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `akoiromantic` |
| 英文名 | Akoiromantic / Lithromantic |
| 中文名 | 单向浪漫倾向（社群流传） |
| 别名 | lithromantic、lith |
| 层级 | 子类（回应型） |
| 上位类 | Greyromantic |
| 对应的轴 | ④ 回应与互惠 |
| 共识度 | 中 |
| 测试适配度 | B |
| 来源 | AUREA 英文完整术语表；误解取自社群图文 |
| 完成度 | 完整 |

### 通俗释义

> 会体验浪漫吸引，但不需要或不希望这份吸引被回应的体验；也可指被回应或进入关系之后，吸引消退、对关系失去兴趣。

### 核心特征

- 会对某个人产生浪漫吸引
- 对方是否回应，对自己来说不一定重要；有人甚至不希望对方回应
- 对方表白、示好或想建立关系时，可能瞬间“下头”，感到尴尬、恶心或想逃开，这是这种体验最明显的特征
- 对方回应了，或两人进入关系之后，这份吸引可能变淡，或对关系失去兴趣

### 体验举例

- 喜欢一个人很久，只想让这份感情停留在原来的样子；真的有人向你表白时，反而觉得有压力。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Disakoiromantic | 方向相反：akoi 讲自己对别人有吸引，却不需要对方回应；disakoi 讲希望别人对自己有吸引，自己却难以回应 |
| Recipromantic | recip 以对方先有心意为前提；akoi 的吸引不以回应为前提，甚至可以不希望被回应 |

**常见误解**

- **"akoi 的人是不会谈恋爱的人。"** akoi 描述的是吸引和回应之间的关系，不直接决定一个人会不会恋爱。有的人在关系里很投入，也有的人会因为对方回应了而感到吸引变淡。
- **"这是“渣”或者“欲擒故纵”吗？"** 不是。“渣”是主观故意玩弄感情，而单向浪漫倾向者的痛苦是真实的。对方回应时，那种厌恶感往往是生理性的（不受大脑控制），他们往往比对方更自责，觉得自己搞砸了一切。
- **"这是一种心理疾病，需要治愈吗？"** 不一定。在多元性、浪漫倾向的视角下，这被视为一种取向。很多人接纳了自己的状态后，选择享受单身的快乐，或建立非传统的亲密关系（如 QPR），并不需要被“矫正”。

### 社区定义

akoi 和 lith 两个词都有人在用，细节上的说法不完全相同。具体含义由当事人自己说明。常见的说法是原因因人而异，更多是天生的情感偏好：有人觉得“爱人”这件事本身已经完成了情感闭环，对方的回应反而是负担；也有人偏爱永远不会回应的对象（如纸片人、明星），觉得这样的爱安全而完美。

- 身边的人谈论心动，你能听懂，却分不清自己对一个人的在意，是想和对方在一起，还是想好好做朋友。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|

| Platoniromantic（延伸区） | quoi 中的一支：浪漫与柏拉图吸引在自己的体验里分不开 |
| Vexromantic（延伸区） | quoi 中的一支：无法理解浪漫吸引这个概念 |
| Pseudoromantic（延伸区） | pseudo 讲其他吸引的感受与浪漫吸引相似、相互遮盖；quoi 讲的是本人怎样理解与区分它们 |

- **"quoi 一定算在 aro-spec 之内，或一定不算。"** 是否属于 aro-spec，由本人认同决定，没有统一的答案。
- **"只是还没遇到对的人，或是太迟钝。"** 不是。不是缺乏经验，也不是迟钝，而是他们的情感运作方式本身就不照着“友情或爱情”的二分来走。

### 社区定义

quoi 的用法不完全一致：有的人指分不清浪漫与其他吸引，有的人指觉得这个概念不适用，也有人两者都包括。也有人长期在困惑里打转，最后把这份困惑本身当作自己的浪漫取向。

| 渴望浪漫倾向（Cupioromantic） | 渴望说的是"想拥有浪漫关系"；喜好说的是"乐于参与"，两者可以同时成立 |

**常见误解**

- **"喜好浪漫，就一定有浪漫吸引。"** 02 的 3.5 节明确把这两件事分开，喜好不会推出吸引。
