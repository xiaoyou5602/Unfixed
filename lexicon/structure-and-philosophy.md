# 名词库 · 关系结构与理念（维度五）

关系怎样组织：几段、是否排他、分不分主次，以及背后的理念。分类树见 03 的 8.2，格式见 [README](README.md)。

5A 里的「不适用」取值，指的就是维度四的「不寻求伴侣式关系」，定义在 [relationship-forms.md](relationship-forms.md) 里，这里不另设词条。

维度五**只问理想和倾向，不问现状**：现状受机会和环境限制，不代表一个人想要什么。

## CNM / ENM

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `cnm` |
| 英文名 | Consensual non-monogamy / Ethical non-monogamy |
| 中文名 | 合意非单偶 / 道德非单偶 |
| 别名 | CNM、ENM |
| 层级 | 伞 |
| 上位类 | — |
| 对应的轴 | 5A 排他与数量取向 |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | 通用说法；逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 在所有相关者知情同意前提下的非单偶关系总称

### 核心特征

- 讲的是关系的结构：同一时间可以有不止一段伴侣式关系（不一定是恋爱，也可以是其他形式的伴侣关系），或者约定可以和别人有某些亲密
- 前提是所有相关的人都知道、都同意，不是瞒着谁
- 不限于浪漫或性：多段酷儿柏拉图关系（QPR，即比友谊更亲密、但不是恋爱的关系）也可以是非单偶
- 具体怎么安排由当事人商量

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Polyamory | polyamory 是 CNM 下的一种，强调同时拥有多段亲密或承诺关系；CNM 还包括以性为主的开放式关系等安排 |
| Open relationship | 开放式关系也在 CNM 伞下，通常以一段核心关系为基础，对外多是性方面的关系 |
| Relationship anarchy（RA） | RA 是组织关系的原则（不预设等级、逐项定制），和伴侣数量无关：只有一段关系，甚至没有伴侣式关系的人，也可以是 RA |
| Monogamy | 单偶是同时只有一段伴侣式关系并保持排他；单偶不限于浪漫，排他的 QPR 也是单偶 |
| 出轨 | 出轨是瞒着伴侣、违背约定；CNM 的前提正是所有相关者知情同意 |

**常见误解**

- **"非单偶就是不认真、随便。"** CNM 对沟通和约定的要求往往更多，很多人的每段关系都是长期、认真的。
- **"非单偶一定和性有关。"** 不一定。多段 QPR、一段浪漫关系加一段 QPR，都可以是非单偶，可以完全不涉及性。
- **"无浪漫倾向（aro）或无性恋（ace）的人一定是（或一定不是）非单偶。"** 吸引和关系结构是两件事，光谱内外的人都可能选择任何一种结构。
- **"现在只有一位伴侣，就不算 CNM。"** 维度五问的是理想和倾向；现在有几段关系，不决定你想要什么样的结构。

### 社区定义

CNM 和 ENM 指的是同一类安排，只是用词侧重不同：一个强调"大家都同意"，一个强调"合乎伦理"。多元之爱（polyamory）、开放式关系都在这把伞下。这里的"关系"不限于浪漫关系：多段 QPR、浪漫关系加 QPR 的组合，同样可以是非单偶。

## Monogamy

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `monogamy` |
| 英文名 | Monogamy |
| 中文名 | 单偶 / 一对一 |
| 别名 | — |
| 层级 | 节点 |
| 上位类 | — |
| 对应的轴 | 5A |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | 通用说法；逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 同一时间只有一段伴侣式关系，并且彼此排他

### 核心特征

- 同一时间只维持一段伴侣式关系，不同时和多人保持这类关系
- 排他：这段关系里，双方都只和对方发展亲密或承诺的关系
- 这里的伴侣式关系不一定是恋爱。排他的酷儿柏拉图关系（QPR）同样是单偶结构
- 这个词说的是关系的结构，不说明一个人对别人有没有好感，也不评价哪种结构更好

### 体验举例

小周和一位伴侣交往多年，两人约好彼此排他，只和对方发展亲密或承诺的关系。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| CNM / ENM | 与单偶相对：CNM 是同时有多段关系，且相关的人都知情同意；单偶是同时只有一段伴侣式关系并保持排他 |
| 出轨 | 出轨是瞒着伴侣、违背约定。单偶说的是关系的约定和结构，两者说的不是同一件事 |

**常见误解**

- **"单偶的人不会对别人有好感。"** 单偶说的是关系的结构，不说明一个人会不会对别人有吸引或好感。
- **"单偶只适用于恋爱。"** 排他的 QPR 也是单偶结构，见核心特征。
- **"单偶的人更专情，非单偶的人就不专情。"** 关系的结构和感情的深浅没有必然联系。

## Polyamory

| 层级 | 伞/节点 |
| 上位类 | CNM / ENM |
| 对应的轴 | 5A |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | 通用说法；逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 同时拥有多段亲密或承诺关系，各方都知情同意

### 核心特征

- 同时有多段关系，而且每段关系都包含情感上的亲密，或彼此承诺
- 各方都知道这个安排，也都同意，关系怎么相处由相关的人商量
- 这些关系可以是恋爱，也可以是其他形式的亲密或承诺关系
- 多元之爱下面还分层级式与非层级式，以及独立多元之爱（solo polyamory）等形式

### 体验举例

小陈同时和两个人都有亲密、彼此承诺的关系，三人都知道这个安排，也都同意。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| CNM / ENM | 多元之爱是 CNM 下的一种，强调同时有多段亲密或承诺关系；CNM 还包括以性为主的开放式关系等安排 |
| Open relationship | 开放式关系以一段核心关系为基础，对外的关系多以性为主；多元之爱的各段关系都包含亲密或承诺 |
| Monogamy | 单偶是同时只有一段伴侣式关系并保持排他，与多元之爱相反 |

**常见误解**

- **"多元之爱就是同时和很多人乱来。"** 多元之爱讲的是每段关系都有亲密或承诺，且各方都知情同意。关系的多少不是判断标准。
- **"多元之爱一定是恋爱。"** 多元之爱的关系可以是恋爱，也可以是其他形式的亲密或承诺关系。
- **"现在只有一段关系，就不能算多元之爱。"** 这个词描述的是理想中的结构。现在有几段关系，不决定一个人想要什么结构。

## 层级式 / 非层级式

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `hierarchy` |
| 英文名 | Hierarchical / Non-hierarchical polyamory |
| 中文名 | 层级式 / 非层级式 |
| 别名 | 主要伴侣 / 次要伴侣（primary / secondary） |
| 层级 | 子类 |
| 上位类 | Polyamory |
| 对应的轴 | 5B 等级观 |
| 共识度 | 中 |
| 测试适配度 | A |
| 来源 | 通用说法；逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 多段关系之间是否预先分出主次：层级式会预设"主要伴侣"和"次要伴侣"，非层级式则不预设

### 核心特征

- **层级式**：预先分出主要伴侣和次要伴侣，主次在一开始就定好
- **非层级式**：不预先规定主次。关系之间自然会有亲疏，但不事先定好谁排第一
- 这一对说法放在多元之爱之下，用来区分多段关系怎么排主次
- 这一项测的是理想中的安排，不是现在有几段关系，也不是现在谁最亲近

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 独立多元之爱（solo polyamory） | 独立多元之爱讲的是生活上保持独立，不以融合生活为基础；层级与否是另一条轴。独立多元之爱的人可以参与有层级的关系网络 |
| RA（关系无政府主义） | RA 同样不预设关系之间的等级。但 RA 是组织关系的原则，还包括逐项协商、不由名分决定重要性；层级式与否只看有没有预先分出主次 |

**常见误解**

- **"层级式就是不尊重次要的伴侣。"** 层级式描述的是预先分出的主次。怎样对待每一位伴侣，是关系里具体的相处方式，由相关的人商量，不由这个词决定。
- **"非层级式就是每段关系都一样亲近。"** 不预设主次不等于没有亲疏。也有人会说关系自然有优先，但不提前规定，这同样属于非层级式。
- **"有一位最亲密的伴侣，就一定是层级式。"** 理想中的安排和现实里谁最亲近不是同一件事。这里问的是打算怎样安排，要不要预先分出主次。

## Solo polyamory

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `solo-polyamory` |
| 英文名 | Solo polyamory |
| 中文名 | 独立多元之爱 |
| 别名 | solo poly |
| 层级 | 子类 |
| 上位类 | Polyamory |
| 对应的轴 | 5A，结合 4B 对生活融合的偏好 |
| 共识度 | 中 |
| 测试适配度 | B |
| 来源 | Amy Gahran 对 solo polyamory 的说明（solopoly.net）；作者本人的用法 |
| 完成度 | 完整 |

### 通俗释义

> 对合意的多段关系持开放态度，但更重视以独立个体生活，通常不追求和伴侣在身份、住所或财务上融为一体

### 核心特征

- 对合意的非单偶关系持开放态度，也就是接受多段关系的结构
- 通常不追求和伴侣融合身份、住所或财务等生活基础，重视以独立个体生活
- 当前可以没有伴侣式关系，也可以有一段或多段关系
- 也可能参与有主次之分（层级式）的关系网络

### 体验举例

小林和一位伴侣交往了几年，两人各自住，财务也分开，生活上没有融合成一个单位。小林同时也对合意的其他关系保持开放。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 多元之爱 | 多元之爱说的是结构，即同时有多段亲密或承诺关系；独立多元之爱是多元之爱的一种，强调在生活上保持独立 |
| 单身 | 单身指当前没有伴侣式关系。独立多元之爱说的是对关系和生活的态度，两者可以同时出现，也可以分开 |
| 层级式 / 非层级式 | 层级式是另一条轴。独立多元之爱可以参与有层级的关系网络，也可以不分主次 |

**常见误解**

- **"独立多元之爱的人一定没有伴侣。"** 定义里当前可以有零段、一段或多段关系。有没有伴侣是现状，不决定这个词是否适用。
- **"独立多元之爱就是不投入感情。"** 这里的独立指的是生活基础上不融合，不是情感上不投入。

### 社区定义

这个词的用法来自 Amy Gahran 的个人说明。她的写法不替所有实践者下定义，不同的人对它的理解可能略有不同。

## 厨房餐桌式 / 平行式

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `kitchen-table-parallel` |
| 英文名 | Kitchen table / Parallel polyamory |
| 中文名 | 厨房餐桌式 / 平行式 |
| 别名 | — |
| 层级 | 子类（实践风格） |
| 上位类 | Polyamory |
| 对应的轴 | 实践细节，不单独设题 |
| 共识度 | 中 |
| 测试适配度 | C |
| 来源 | 通用说法；逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 多元之爱里的两种相处风格：一种是各段关系的人彼此熟络，另一种是各段关系互不交集

### 核心特征

- **厨房餐桌式**：各段关系的人彼此认识、相处熟络，互相也有往来
- **平行式**：各段关系彼此分开，互不交集，各过各的
- 这两种说的是怎样相处，不决定一个人是不是多元之爱

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 多元之爱 | 多元之爱说的是结构，即同时有多段亲密或承诺关系；厨房餐桌式与平行式说的是这些关系之间的相处方式 |
| 层级式 / 非层级式 | 层级说的是主次，厨房餐桌式与平行式说的是彼此熟不熟，两者是不同的问题 |

**常见误解**

- **"厨房餐桌式才算真正的多元之爱。"** 两种风格都是多元之爱里的实践方式，不分高低。
- **"平行式就是关系不认真。"** 平行式只说各段关系彼此不往来，不说明每段关系的投入程度。

## Open relationship

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `open-relationship` |
| 英文名 | Open relationship |
| 中文名 | 开放式关系 |
| 别名 | — |
| 层级 | 节点 |
| 上位类 | CNM / ENM |
| 对应的轴 | 5A，结合 4B |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | 通用说法；逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 以一段核心关系为基础，允许与外部发生（多为性方面的）关系

### 核心特征

- 有一段被当作核心的关系，它是这个安排的基础
- 核心关系之外，允许与别人发生关系，而且这些外部关系多为性方面的
- 外部关系的界限和怎么告知，由相关的人商量约定
- 无性恋（ace）与有性恋（allo）的伴侣，为协调彼此的需求而约定开放，也属于这类安排，不单设名称

### 体验举例

小宁和伴侣有一段核心关系，两人约定，彼此之外可以和别人有性方面的亲密，具体怎么做由两人商量。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| CNM / ENM | 开放式关系属于 CNM 的伞下，前提同样是相关的人都知情同意 |
| 多元之爱 | 多元之爱的各段关系都包含亲密或承诺；开放式关系的外部关系多为性方面，并以一段核心关系为基础 |
| 单偶 | 单偶要求排他，开放式关系允许外部关系，因此属于非单偶 |

**常见误解**

- **"开放式关系就是随便、没有感情。"** 开放式关系以一段核心关系为基础，这段关系可以很认真地经营。
- **"开放式关系就是没有任何规则。"** 外部关系的界限是双方约定的，约定也是一种规则。

## Ambiamorous

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `ambiamorous` |
| 英文名 | Ambiamorous |
| 中文名 | 两可 |
| 别名 | — |
| 层级 | 节点 |
| 上位类 | — |
| 对应的轴 | 5A |
| 共识度 | 低 |
| 测试适配度 | B |
| 来源 | 逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 单偶和非单偶的结构都能接受，也都能自在地过

### 核心特征

- 对"只有一段关系"和"有多段关系"两种安排都能接受
- 在哪一种安排里都能过得自在，不会因为是其中一种而勉强
- 这是对理想结构的态度，和现在实际有几段关系不是一回事

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 单偶 | 单偶是同时只有一段伴侣式关系并保持排他。两可不是某一种结构，而是对两种都能接受 |
| 非单偶（CNM / ENM） | 非单偶是同时有多段关系、相关的人都知情同意。两可则是对它也能接受、也能自在 |
| 未定／随缘 | 两可是已经能接受两种安排。未定或随缘是还没想好要哪一种，或者不想先定下来，属于作答时的选择，不是一种关系结构 |

**常见误解**

- **"两可就是没有立场。"** 两可是对两种安排都能接受，这本身就是一种立场。
- **"两可的人迟早要选一边。"** 两可描述的是现在的理想，不预设以后会怎样。

### 社区定义

这个词的来源有限，上面的写法是目前能找到的意思，不同地方的用法可能有出入。

## Relationship anarchy

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `relationship-anarchy` |
| 英文名 | Relationship anarchy |
| 中文名 | 关系无政府主义 |
| 别名 | RA |
| 层级 | 节点·可叠加（理念，与结构正交） |
| 上位类 | — |
| 对应的轴 | 5B 等级观、5C 关系类别观、5D 规则来源 |
| 共识度 | 高 |
| 测试适配度 | B |
| 来源 | Andie Nordgren 2006 年瑞典语宣言及 2012 年英语改写；已核实 |
| 完成度 | 完整 |

### 通俗释义

> 一种组织关系的原则：不预设关系之间的等级，每段关系由当事人逐项协商，不由"恋人""朋友"这类名分决定它有多重要

### 核心特征

- 不预设关系之间的等级：一段关系不会因为是恋爱或友谊，就自动比别的关系更重要
- 每段关系由当事人逐项协商，怎么相处、怎么约定，都是这段关系自己的事
- 尊重彼此的自主，不用规则去约束对方的其他关系
- 这是一种组织关系的原则，和有几段伴侣式关系无关。没有任何浪漫或性关系的人，也可以是 RA

### 体验举例

小唐和伴侣的相处方式，与和朋友的相处方式并不相同。两段关系各自谈过，没有照着同一套模板走。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 多元之爱 / 开放式关系 | 这些说的是关系的结构，即有几段、是否排他。RA 说的是怎样组织关系。两者可以叠加，也可以只有其中一个 |
| 非层级式 | 两者都不预设主次。非层级式只说不预先分主次；RA 还包括逐项协商、不由名分决定重要性 |
| 恋爱规范性批判 | 两者都不把恋爱放在默认的最高位置。RA 讲的是怎样组织每段关系；批判则是反对"人人都该追求排他的伴侣关系"这一假设 |

**常见误解**

- **"RA 就是非单偶。"** RA 与伴侣数量无关，RA 的人可以是单偶，也可以是非单偶。
- **"RA 就是什么规则都没有。"** RA 是每段关系各自定规则，并尊重对方的其他关系，不靠现成的模板。这不等于没有规则。
- **"RA 就是不认真对待关系。"** RA 强调逐项协商，每段关系都需要当事人自己谈清楚。

## 恋爱规范性批判

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `amatonormativity-critique` |
| 英文名 | Critique of amatonormativity |
| 中文名 | 恋爱规范性批判（拟，amatonormativity 暂无统一译法） |
| 别名 | 反 amatonormativity |
| 层级 | 节点·可叠加（理念） |
| 上位类 | — |
| 对应的轴 | 5C，另加价值题 |
| 共识度 | 高 |
| 测试适配度 | B |
| 来源 | Elizabeth Brake《Minimizing Marriage》（2012）及其本人说明；已核实 |
| 完成度 | 完整 |

### 通俗释义

> 反对一种普遍假设：这种假设认为每个人都会在一段排他、浪漫、长期的伴侣关系里过得更好，并且人人都在追求这样的关系

### 核心特征

- 指出社会上常把排他、浪漫、长期的伴侣关系当作默认的人生方向
- 批判的是这个假设本身，不是批评谁选择了恋爱或伴侣关系
- 不预设恋爱关系天然比其他关系更重要

### 体验举例

朋友问小方什么时候找一个固定的伴侣。小方觉得这个问题预设了恋爱是人生的必经之路，但并不是在批评朋友的选择。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 单偶 | 单偶是一种关系结构。反对恋爱规范性不等于选择非单偶，两者可以分开看，各种结构的人都可以认同这个批判 |
| RA | RA 讲的是怎样组织每段关系，批判讲的是反对一种默认假设；两者可以同时成立 |
| 离开关系电梯 | 批判针对"人人都该追求排他的伴侣关系"这一假设，离开电梯针对的是关系的推进路线；两者可以同时成立，也可以分开 |

**常见误解**

- **"反恋爱规范性的人不喜欢恋爱。"** 批判的是把恋爱当作默认目标的假设。有人很喜欢恋爱，也认同这个批判。
- **"这个立场是在反对结婚或伴侣关系。"** 批判针对的是"人人都该追求这样的关系"这一假设，不是否定某一段具体的关系。

### 社区定义

这个词出自哲学家 Elizabeth Brake 的 *Minimizing Marriage*（2012）。

## 离开关系电梯

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `off-escalator` |
| 英文名 | Off-escalator |
| 中文名 | 离开关系电梯 |
| 别名 | relationship escalator（关系电梯） |
| 层级 | 节点·可叠加（理念） |
| 上位类 | — |
| 对应的轴 | 5E 对关系电梯的态度 |
| 共识度 | 中 |
| 测试适配度 | B |
| 来源 | Amy Gahran 的文章与书籍注释（offescalator.com）；作者表示并非她造词，确切起源不详 |
| 完成度 | 完整 |

### 通俗释义

> 不按社会默认的关系推进路线走，或只取其中的一部分

### 核心特征

- "关系电梯"指社会上默认的推进路线：约会、确定关系、同居、结婚，之后可能还有生育
- 离开电梯，就是不照这条路线推进，或者只取其中一部分
- 这说的是对推进路线的选择，不是对某段具体关系的评价
- 这一项问的是理想中的推进方式，不是现在关系进展到了哪一步

### 体验举例

小梁和伴侣交往很久，两人一起生活，但都不想结婚。这段关系按照两人自己的节奏走。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 恋爱规范性批判 | 批判针对的是一种假设，离开电梯针对的是关系的推进路线；两者可以同时出现，也可以分开 |
| RA | RA 讲的是每段关系怎样组织，离开电梯讲的是是否照社会默认的路线推进 |
| 单偶 / 非单偶 | 结构和推进路线是两条不同的轴。单偶可以离开电梯，非单偶也可以照着电梯走 |

**常见误解**

- **"离开关系电梯就是不认真经营关系。"** 离开的是推进路线，关系认不认真要看具体的相处方式。
- **"离开关系电梯就是拒绝结婚或生育。"** 这个词只说不按这条路线推进，或只取其中一部分。想不想结婚或生育，是另外的问题，要看个人。

### 社区定义

这个词的确切起源不详。Amy Gahran 在文章和书中用过它，但她本人说这并不是她造的词。

## 友谊中心

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `friendship-centered` |
| 英文名 | — |
| 中文名 | 友谊中心 / 以选择的家人为中心 |
| 别名 | — |
| 层级 | 节点·可叠加（理念） |
| 上位类 | — |
| 对应的轴 | 5C + 4A |
| 共识度 | 中 |
| 测试适配度 | B |
| 来源 | 逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 把友谊或社群，而不是伴侣关系，视为生活里的核心支持

### 核心特征

- 生活里的核心支持放在朋友或社群身上
- 说的是核心支持放在哪里，不是说不要伴侣关系
- 这里的支持，指的是遇到事情时想找的人、日常里陪伴自己的人

### 体验举例

小邓的周末通常和几位老朋友一起做饭、散步。遇到事情，小邓先找这几位朋友商量。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 恋爱规范性批判 | 批判的是恋爱被当作默认的最高目标；友谊中心说的是生活的核心支持放在哪里。两者都让恋爱不再是唯一的中心，但说的是不同的事 |
| 单偶 / 多元之爱 | 这些说的是伴侣关系的结构。核心支持放在哪里是另一个问题，两者可以分开看 |
| RA | RA 讲的是每段关系怎样组织；友谊中心讲的是核心支持放在哪里。两者可以同时成立 |

**常见误解**

- **"友谊中心就是不要伴侣。"** 这个立场说的是核心支持放在哪里，不是排斥伴侣关系。
- **"以友谊为中心的人对恋爱没有感情。"** 这个立场不说明一个人对恋爱有多少感情，只说明生活里的核心支持放在哪里。
