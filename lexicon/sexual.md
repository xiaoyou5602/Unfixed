## Ace-spec

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `ace-spec` |
| 英文名 | Ace-spec |
| 中文名 | 无性恋光谱（通行） |
| 别名 | asexual spectrum、acespec；口语里也常简称 ace |
| 层级 | 伞 |
| 上位类 | Aspec |
| 对应的轴 | 性侧的 ①–⑨ 整体 |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | AUREA 中文基本术语（aro／ace、光谱）；AVEN 等无性恋社群的常用说法；逐条直链待补 |
| 完成度 | 完整 |

### 通俗释义

> 很少或不体验性吸引、以有条件或非典型方式体验，或与"性吸引"这个概念关系复杂的人

### 核心特征

- 讲的是性吸引：会不会对某个具体的人产生想和 ta 发生性接触的念头
- 这种念头在自己身上很少出现、很淡、要特定条件，或者说不清算不算
- 只管吸引，不管性欲、对性的态度和性经历，这几件事要分开看
- 它是一片范围，下面有很多更具体的词；用不用、用哪个，由本人决定

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Asexual | asexual 是伞下的一个点，指很少或从不体验性吸引；ace-spec 是整片范围。口语里 "ace" 两种意思都有人用 |
| Grey-asexual / Greysexual | grey 是伞下"介于中间"的那一段，本身也是一把小伞 |
| Aro-spec | aro-spec 讲的是浪漫吸引。两者可以分开：ace-spec 的人可以有浪漫吸引（alloace），也可以没有（aroace） |
| Aspec | aspec 是更大的总伞，包含 aro-spec 和 ace-spec |
| 禁欲（celibacy） | 禁欲是选择不发生性行为，讲的是行为；ace-spec 讲的是吸引。有性吸引的人也可以禁欲，ace-spec 的人也可以有性生活 |
| 日常说的"性冷淡" | 中文里"性冷淡"多指性欲或性兴趣低，常带医学或贬义色彩。ace-spec 讲的是吸引，和性欲高低是两回事：有性欲的人也可以是 ace-spec |

**常见误解**

- **"ace 就是没有性欲。"** 有没有性欲（libido）和有没有性吸引是两件事。不少 ace-spec 的人有性欲，只是不指向任何人。
- **"ace 一定厌恶性。"** 对性的态度因人而异：有人排斥，有人无所谓，也有人喜欢（sex-favorable）。态度不决定是不是 ace-spec。
- **"没有过性经历的人才会这么想。"** 经历不是门槛：没有过性经历不是 ace 的证据，有过性经历也不排除是 ace。关键在于有没有感到过性吸引。
- **"这是身体或激素出了问题，需要治。"** 社群的立场是，这是一种取向，不是疾病。如果本人对自己的身体变化有困扰，那是另一件值得认真对待的事，但它和"是不是 ace"不能互相推出。
- **"命中了虚构角色或自己这类对象，就是 ace-spec。"** fictosexual、autosexual 描述的是吸引指向谁，不单独决定归属。

### 社区定义

asexual、greysexual、demisexual 等都在 ace-spec 这把伞下面。和浪漫侧一样，伞的范围有宽有窄；这个测试用宽的范围，和“性吸引”这个概念关系复杂的 quoisexual 也在伞下。

社群反复强调的一点是：性吸引、性欲、对性的态度、性行为是四件不同的事。ace-spec 只关乎第一件。一个人是不是 ace-spec，最终由本人认同决定。

## Asexual

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `asexual` |
| 英文名 | Asexual |
| 中文名 | 无性恋（通行） |
| 别名 | ace（也常用来泛指整个 ace-spec） |
| 层级 | 节点 |
| 上位类 | Ace-spec |
| 对应的轴 | ② 频率与强度 |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | 主树通用词；逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 很少或从不体验性吸引的人，也就是很少或从来不会对某个具体的人产生想发生性接触的念头。这不等于没有性欲，也不等于厌恶性。

### 核心特征

- 讲的是性吸引的多少：对某个人，会不会产生想和 ta 发生性接触的念头
- 这种念头很少出现，或者从来不出现；即使有，也很淡
- 只说吸引，不说性欲、对性的态度，也不说有没有性行为，这几件事要分开看
- 它是 ace-spec 伞下面的一个具体的点，描述"很少或从不"的这一端；介于无性和有性之间的那一段，见 greysexual

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Ace-spec | 无性恋光谱是整片范围，无性恋只是其中一个点 |
| Greysexual | 灰性恋是性吸引很弱、只偶尔有，或不确定那算不算；无性恋是很少或从不体验 |
| 性欲（libido） | 性欲是身体上的性冲动，不一定指向任何人；无性恋讲的是对具体的人有没有性吸引。两者可以分开 |
| 禁欲（celibacy） | 禁欲是选择不发生性行为，讲的是行为；无性恋讲的是吸引 |

**常见误解**

- **"无性恋就是没有性欲。"** 不少无性恋的人有性欲，只是不指向任何具体的人。
- **"无性恋一定厌恶性。"** 对性的态度因人而异：有人排斥，有人无所谓，也有人喜欢。态度不决定是不是无性恋。
- **"没有性经历的人才会这样。"** 经历不是判断的依据：没有性经历不能说明是无性恋，有过性经历也不排除。
- **"这是身体或激素出了问题。"** 社群把它看作一种取向，不是疾病。是否有困扰是另一件事，它不能推出是不是无性恋。

### 社区定义

口语里 "ace" 有时指整个无性恋光谱，有时只指这个点，两种用法都常见。这个测试里说"无性恋"时，指的是这个点。

## Greysexual

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `greysexual` |
| 英文名 | Grey-asexual / Greysexual |
| 中文名 | 灰性恋、灰色无性恋（通行） |
| 别名 | grey-ace、graysexual |
| 层级 | 伞/节点 |
| 上位类 | Ace-spec |
| 对应的轴 | ② 频率与强度；① 分类方式（有点模糊） |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | 主树通用词；逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 很少、很弱或只在特定情况下体验性吸引，或者不确定自己的那种感觉算不算性吸引的人。它处在无性恋和有性恋之间的那一段。

### 核心特征

- 性吸引确实有，但很少出现，或者强度很弱
- 有时才会有，而且只在特定的情况下出现
- 也可能是不确定：有某种感觉，却分不清那算不算性吸引
- 它是一把伞，下面还可以再细分出 demisexual、aceflux 等更具体的说法；用哪个，由本人决定

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Asexual | 无性恋指很少或从不体验性吸引；灰性恋是性吸引存在但很弱、很少，或分不清那算不算 |
| Demisexual | 半性恋是灰性恋伞下的一个子类，指只有建立深厚情感连接之后才会有性吸引 |
| Allosexual | 有性恋的体验方式不在无性恋光谱之内；灰性恋仍在这把伞下面 |
| Quoisexual | 困惑性恋讲的是分不清，或觉得概念不适用；灰性恋讲的是性吸引少、弱或不确定。两者可以同时出现 |

**常见误解**

- **"灰性恋就是没想清楚的无性恋。"** 灰性恋是一个独立的说法。有人会长期用这个词，也有人不用。
- **"灰性恋一定有条件。"** 有没有条件因人而异。条件型只是伞下的一类，例如 demisexual。
- **"灰性恋就是性吸引比较强的无性恋。"** 灰性恋讲的是性吸引少、弱，或不确定，并不是按强弱排一个高低。

### 社区定义

对灰色这一段的边界，社群的看法不完全一样：有人只把"很少、很弱"算进来，也有人把"不确定那算不算"算进来。这个测试两种都包括。

## Demisexual

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `demisexual` |
| 英文名 | Demisexual |
| 中文名 | 半性恋（通行） |
| 别名 | — |
| 层级 | 子类（条件型） |
| 上位类 | Grey-asexual / Greysexual |
| 对应的轴 | ③ 触发条件 |
| 共识度 | 高 |
| 测试适配度 | B |
| 来源 | 主树通用词；逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 只有在与某人建立深厚的情感连接之后，才可能对其产生性吸引的人。关键在于吸引本身需要连接才会出现，而不是"愿意发生性关系"需要连接。

### 核心特征

- 性吸引要等情感连接建立起来才可能出现：先有情感上的亲近，之后才可能有性吸引
- 情感连接的深浅因人而异，这个词不规定要多久、要达到什么程度
- 说的是"吸引要不要等连接"，不是"愿不愿意发生性关系"，后者是另一件事
- 这里的连接指深厚的情感连接，不一定是恋爱关系

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 半浪漫倾向（Demiromantic） | 同样需要先有情感连接，但讲的是浪漫吸引。两者可以同时出现，也可以只有一种 |
| Grey-asexual / Greysexual | 灰性恋是伞，半性恋是伞下的一个子类，指需要条件的那一种 |
| Recipsexual | 互惠性恋需要先知道对方对自己有性吸引；半性恋需要先有深厚的情感连接。两种条件不同 |
| Asexual | 无性恋指很少或从不体验性吸引；半性恋在情感连接之后会有性吸引，只是需要这个条件 |

**常见误解**

- **"半性恋就是只对很熟的人才有性方面的想法。"** 这个词讲的是情感连接，不是熟不熟。两者不完全一样。
- **"半性恋一定要恋爱之后才有性吸引。"** 连接不一定是恋爱关系，它指的是深厚的情感连接；和是否恋爱是两回事。
- **"半性恋的人对性一定保守。"** 对性的态度因人而异，和吸引需要什么条件没有直接关系。

## Recipsexual

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `recipsexual` |
| 英文名 | Recipsexual / Reciprosexual |
| 中文名 | 互惠性恋（拟，与浪漫侧对齐） |
| 别名 | reciprosexual |
| 层级 | 子类（条件型） |
| 上位类 | Grey-asexual / Greysexual |
| 对应的轴 | ③ 触发条件 |
| 共识度 | 中 |
| 测试适配度 | B |
| 来源 | 主树通用词；逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 只有在知道对方对自己也有性吸引之后，才可能对对方产生性吸引的人。

### 核心特征

- 性吸引要等对方先有意才会出现，对方的心意是这里的关键条件
- 这里讲的是"得知对方有意"，并不限定是怎样得知的
- 它是条件型的一种，和半性恋的条件不同：一个看情感连接，一个看对方有没有意思
- 吸引是在知道对方有意之后才出现的，是回应式的

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 单向性恋（Akoisexual） | 单向性恋是有吸引但不希望被回应；互惠性恋是要先知道对方有意才会有吸引。两者方向不同 |
| 半性恋（Demisexual） | 半性恋需要情感连接，互惠性恋需要知道对方有性吸引。两种条件可以同时符合 |

**常见误解**

- **"互惠性恋的人不敢主动。"** 这个词讲的是吸引的条件，不是主动性或胆量。
- **"互惠性恋的人只能和对方在一起。"** 这个词讲的是吸引的条件，和怎样相处、要不要建立关系没有直接关系。

### 社区定义

英文有两种拼法，Recipsexual 与 Reciprosexual 指的是同一个词。中文名是按浪漫侧的译法拟的，社群里还没有通行的中文叫法。

## Fraysexual

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `fraysexual` |
| 英文名 | Fraysexual |
| 中文名 | 磨损性恋（拟） |
| 别名 | — |
| 层级 | 子类（条件型） |
| 上位类 | Grey-asexual / Greysexual |
| 对应的轴 | ③ 触发条件 |
| 共识度 | 中 |
| 测试适配度 | B |
| 来源 | 主树通用词；逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 性吸引主要指向还不太熟悉的人，随着了解加深而减弱的人。它和半性恋的方向相反。

### 核心特征

- 吸引多出现在刚认识、还不太了解对方的阶段
- 随着了解加深，对这个人的性吸引会慢慢减弱
- 说的是吸引随了解而变化，不是对亲密关系或承诺的态度
- 和半性恋方向相反：半性恋是建立了深厚连接才有吸引，磨损性恋是了解越多吸引越淡

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 半性恋（Demisexual） | 方向相反：半性恋在建立连接之后才会有性吸引，磨损性恋在了解之后吸引会减弱 |
| 新鲜感消退 | 一般的新鲜感过去，讲的是情感或兴趣的变化；磨损性恋讲的是对特定对象的性吸引随了解而变弱 |
| 害怕承诺 | 磨损性恋讲的是吸引随了解的变化，不是对承诺的态度，两者是不同的事 |

**常见误解**

- **"磨损性恋就是对人没兴趣，或只图新鲜。"** 它描述的是性吸引随了解而变化，不是对人整体的评价，也不是对新鲜感的追求。
- **"磨损性恋的人一定害怕承诺。"** 这个词不描述对承诺的态度。
- **"一开始一定要很有感觉。"** 这个词只讲吸引主要出现在还不熟悉的时候，并不规定强度。

## Akoisexual

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `akoisexual` |
| 英文名 | Akoisexual / Lithsexual |
| 中文名 | 单向性恋（拟） |
| 别名 | lithsexual |
| 层级 | 子类（回应型） |
| 上位类 | Grey-asexual / Greysexual |
| 对应的轴 | ④ 回应与互惠 |
| 共识度 | 中 |
| 测试适配度 | B |
| 来源 | 主树通用词；逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 会体验性吸引，但不希望被对方回应，或者被回应之后吸引就消退的人。

### 核心特征

- 会对某个具体的人有性方面的吸引，这一点和有性恋相似
- 对"被回应"这件事有自己的态度：可能不希望对方有同样的回应
- 也可能是被回应、或进入关系之后，吸引就消退、失去兴趣
- 说的是对回应的态度，不是有没有吸引

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 无性恋（Asexual） | 无性恋是很少或从不体验性吸引；单向性恋有性吸引，只是不希望被回应，或被回应后消退 |
| 互惠性恋（Recipsexual） | 互惠性恋要先知道对方有意，才会有吸引；单向性恋是有吸引，却不希望对方回应。两者方向不同 |
| 被欲性恋（Disakoisexual） | 被欲性恋是希望被别人吸引，自己却无法回应；单向性恋是自己有吸引，却不希望对方回应。两者方向相反 |

**常见误解**

- **"单向性恋就是暗恋。"** 不一定。这个词讲的是对回应的态度，不一定是藏着不说的暗恋。
- **"不希望被回应，就是不喜欢对方。"** 吸引和不希望被回应可以同时存在，这个词讲的正是这一点。
- **"单向性恋的人不会谈恋爱。"** 这个词讲的是性吸引和回应，和是否恋爱没有直接关系。

### 社区定义

社群里有人只用其中一种情况来理解这个词：有人指"不希望被回应"，有人指"被回应或进入关系后消退"，也有人两种都算。这个测试两种都包括。

## Aceflux

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `aceflux` |
| 英文名 | Aceflux |
| 中文名 | 波动无性恋（拟） |
| 别名 | — |
| 层级 | 子类（时间型） |
| 上位类 | Grey-asexual / Greysexual |
| 对应的轴 | ⑤ 时间模式 |
| 共识度 | 中 |
| 测试适配度 | C |
| 来源 | 主树通用词；逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 性吸引的强弱随时间在无性恋光谱上来回波动的人。

### 核心特征

- 不是一直保持不变：有时吸引多一些，有时少一些
- 波动可以在光谱之内来回移动，这个词关注的是变化的节奏
- 它描述的是变化的模式，不解释变化的原因
- 说的是一段时间里的整体模式，不是某一次的体验

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 尖峰无性恋（Acespike） | 尖峰是平时几乎没有，偶尔出现一次强烈而短暂的高峰；波动是强弱持续地变化，不一定有明显的尖峰 |
| 灰性恋（Greysexual） | 灰性恋讲的是性吸引的强度或确定性；波动无性恋讲的是随时间的变化。两者可以同时符合 |
| 困惑性恋（Quoisexual） | 困惑性恋讲的是分不清或不适用；波动讲的是随时间变化。两者不一定同时出现 |

**常见误解**

- **"波动无性恋就是没想清楚自己的取向。"** 它描述的是吸引强弱随时间的变化，不是对自己认识的判断。
- **"'波动'说明这个人不稳定，有问题。"** 这个词只描述变化的模式，不评价一个人的稳定性或心理状态。
- **"有过一次吸引，就是波动无性恋。"** 它讲的是一段时间里的整体节奏，单次体验不决定归属。

## Acespike

### 基本信息

### 通俗释义

> 无法确定自己是否体验性吸引，或无法把它与其他吸引区分开，或觉得"性吸引"这个概念对自己不适用的人。

### 核心特征

- 问题在"分类"：分不清自己这种感觉算不算性吸引
- 可能分不清性吸引和浪漫、感官、审美等其他吸引
- 也可能觉得"性吸引"这套说法对自己不适用，不想硬套
- 讲的是怎样给感受分类，和有没有某种感受是分开的两件事

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 迷惑性恋（Vexsexual，延伸区） | 困惑性恋讲的是分不清、无法区分，或觉得不适用；迷惑性恋讲的是认为自己在光谱内，却因为不理解性吸引而无法进一步描述。两者很接近，可以重叠 |
| 无性恋（Asexual） | 无性恋讲的是性吸引很少或从不；困惑性恋讲的是分不清。两者可以同时出现 |
| 伪性恋（Pseudosexual，延伸区） | 伪性恋可以是其他吸引看起来像性吸引，也可以是分不清类别；两者可以重叠 |

**常见误解**

- **"困惑性恋就是没有性吸引。"** 它讲的是分类上的困惑，不直接说明有没有性吸引。
- **"困惑性恋的人只是还没搞懂。"** 觉得概念不适用，本身也是一种体验，不需要被"搞懂"。
- **"困惑性恋一定不属于无性恋光谱。"** 是否在光谱内由本人决定，这个词不替本人下结论。

### 社区定义

关于它是否属于无性恋光谱，社群的看法并不一致。这个测试把它放在无性恋光谱之下，但是否属于，由本人决定。

### 通俗释义

> 自己和性之间有"断开"感的人：可能有性方面的想象，也会被性相关的内容唤起，但并不渴望自己作为当事人和别人发生性行为。

### 核心特征

- 性方面的想象或唤起可能有，但主要停留在旁观或想象里
- 对"自己作为当事人参与性行为"没有渴望
- 这是关于"自己要不要参与"的说法，不等于对性或对人没有兴趣
- 是可以叠加在其他说法上的标签，不单独决定其他归属

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 性欲 | 性欲是身体上的冲动；旁观性恋讲的是自己是否想作为当事人参与。两者可以同时有，也可以分开 |
| 自我性恋（Autosexual，延伸区） | 自我性恋讲的是吸引指向自己；旁观性恋讲的是自己不渴望参与。两者讲的是不同的事 |
| 渴望性恋（Cupiosexual） | 渴望性恋希望拥有性关系或性行为；旁观性恋不渴望自己作为当事人参与。两者方向相反 |

**常见误解**

- **"旁观性恋就是只能看、不能参与。"** 它讲的是是否渴望自己参与，不是规定能做什么、不能做什么。
- **"旁观性恋是一种性功能的问题。"** 这个词描述的是对自己参与的渴望，不说明身体功能，也不说明原因。
- **"这是一种病理或偏差。"** 这个词不是诊断。它的旧称带有病理化的色彩，社群因此改用现在的名称。

### 社区定义

这个词的旧称 autochorissexualism 由研究者在 2012 年提出，当时带有病理化的色彩；社群之后改用 aegosexual。中文名是拟名。
