## Ace-spec

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `ace-spec` |
| 英文名 | Ace-spec |
| 中文名 | 无性吸引光谱（社群流传） |
| 别名 | asexual spectrum、acespec；无性恋光谱（通行译名）、无性吸引谱系；口语里也常简称 ace |
| 层级 | 伞 |
| 上位类 | Aspec |
| 对应的轴 | 性侧的 ①–⑨ 整体 |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | AUREA 中文基本术语（aro／ace、光谱）；AVEN 等无性恋社群的常用说法；逐条直链待补 |
| 完成度 | 完整 |

### 通俗释义

> 也常译作「无性恋光谱」，包括很少或从不体验性吸引，以及只在特定条件下才会产生性吸引等情况。

### 核心特征

- 讲的是性吸引：会不会对某个具体的人产生想和 ta 发生性接触的念头
- 这种念头在自己身上很少出现、很淡、要特定条件，或者说不清算不算
- 只管吸引，不管性欲、对性的态度和性经历，这几件事要分开看
- 它是一片范围，下面有很多更具体的词；用不用、用哪个，由本人决定

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Asexual | asexual 是伞下的一个点，指很少或从不体验性吸引；ace-spec 是整片范围。口语里 "ace" 两种意思都有人用 |
| Grey-asexual / Greysexual | grey 是伞下"介于中间"的那一段，本身也是一把小伞 |
| Aro-spec | aro-spec 讲的是浪漫吸引。两者可以分开：ace-spec 的人可以有浪漫吸引（alloace），也可以没有（aroace） |
| Aspec | aspec 是更大的总伞，包含 aro-spec 和 ace-spec |
| 禁欲（celibacy） | 禁欲是选择不发生性行为，讲的是行为；ace-spec 讲的是吸引。有性吸引的人也可以禁欲，ace-spec 的人也可以有性生活 |
| 日常说的"性冷淡" | 中文里"性冷淡"多指性欲或性兴趣低，常带医学或贬义色彩。ace-spec 讲的是吸引，和性欲高低是两回事：有性欲的人也可以是 ace-spec |

**常见误解**

- **"ace 就是没有性欲。"** 有没有性欲（libido）和有没有性吸引是两件事。不少 ace-spec 的人有性欲，只是不指向任何人。
- **"ace 一定厌恶性。"** 对性的态度因人而异：有人排斥，有人无所谓，也有人喜欢（sex-favorable）。态度不决定是不是 ace-spec。
- **"没有过性经历的人才会这么想。"** 经历不是门槛：没有过性经历不是 ace 的证据，有过性经历也不排除是 ace。关键在于有没有感到过性吸引。
- **"这是身体或激素出了问题，需要治。"** 社群的立场是，这是一种取向，不是疾病。如果本人对自己的身体变化有困扰，那是另一件值得认真对待的事，但它和"是不是 ace"不能互相推出。
- **"命中了虚构角色或自己这类对象，就是 ace-spec。"** fictosexual、autosexual 描述的是吸引指向谁，不单独决定归属。

### 社区定义

asexual、greysexual、demisexual 等都在 ace-spec 这把伞下面。和浪漫侧一样，伞的范围有宽有窄；这个测试用宽的范围，和“性吸引”这个概念关系复杂的 quoisexual 也在伞下。

社群反复强调的一点是：性吸引、性欲、对性的态度、性行为是四件不同的事。ace-spec 只关乎第一件。一个人是不是 ace-spec，最终由本人认同决定。

## Asexual

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `asexual` |
| 英文名 | Asexual |
| 中文名 | 无性吸引（社群流传） |
| 别名 | ace（也常用来泛指整个 ace-spec）；无性恋（通行译名） |
| 层级 | 节点 |
| 上位类 | Ace-spec |
| 对应的轴 | ② 频率与强度 |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | 主树通用词；逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 也常译作「无性恋」，指很少或从不体验性吸引。

### 核心特征

- 讲的是性吸引的多少：对某个人，会不会产生想和 ta 发生性接触的念头
- 这种念头很少出现，或者从来不出现；即使有，也很淡
- 只说吸引，不说性欲、对性的态度，也不说有没有性行为，这几件事要分开看
- 它是 ace-spec 伞下面的一个具体的点，描述"很少或从不"的这一端；介于无性和有性之间的那一段，见 greysexual

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Ace-spec | 无性吸引光谱是整片范围，无性吸引只是其中一个点 |
| Greysexual | 灰色性吸引是性吸引很弱、只偶尔有，或不确定那算不算；无性吸引是很少或从不体验 |
| 性欲（libido） | 性欲是身体上的性冲动，不一定指向任何人；无性吸引讲的是对具体的人有没有性吸引。两者可以分开 |
| 禁欲（celibacy） | 禁欲是选择不发生性行为，讲的是行为；无性吸引讲的是吸引 |

**常见误解**

- **"无性吸引就是没有性欲。"** 不少无性吸引者有性欲，只是不指向任何具体的人。
- **"无性吸引者一定厌恶性。"** 对性的态度因人而异：有人排斥，有人无所谓，也有人喜欢。态度不决定是不是无性吸引者。
- **"没有性经历的人才会这样。"** 经历不是判断的依据：没有性经历不能说明是无性吸引者，有过性经历也不排除。
- **"这是身体或激素出了问题。"** 社群把它看作一种取向，不是疾病。是否有困扰是另一件事，它不能推出是不是无性吸引者。

### 社区定义

口语里 "ace" 有时指整个无性吸引光谱，有时只指这个点，两种用法都常见。这个测试里说"无性吸引"时，指的是这个点。

中文通行译名是"无性恋"。不少社群成员倡议改称"无性吸引"：「恋」字容易让人把"很少或从不体验性吸引"读成"不谈恋爱、对亲密关系没有向往"，而这个词只讲性吸引，会不会心动、想不想谈恋爱是浪漫吸引那一边的事。这个测试从 2026 年 11 月起以"无性吸引"为主名，"无性恋"照常列出，两个叫法说的是同一件事。

## Greysexual

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `greysexual` |
| 英文名 | Grey-asexual / Greysexual |
| 中文名 | 灰色性吸引（拟） |
| 别名 | grey-ace、graysexual；灰性恋、灰色无性恋（通行译名）；灰色性向（中文维基） |
| 层级 | 伞/节点 |
| 上位类 | Ace-spec |
| 对应的轴 | ② 频率与强度；① 分类方式（有点模糊） |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | 主树通用词；逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 也常译作「灰性恋」，指很少、很弱或只在特定情况下体验性吸引，或者不确定自己的那种感觉算不算性吸引的人。它处在无性吸引和有性吸引之间的那一段。

### 核心特征

- 性吸引确实有，但很少出现，或者强度很弱
- 有时才会有，而且只在特定的情况下出现
- 也可能是不确定：有某种感觉，却分不清那算不算性吸引
- 它是一把伞，下面还可以再细分出 demisexual、aceflux 等更具体的说法；用哪个，由本人决定

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Asexual | 无性吸引指很少或从不体验性吸引；灰色性吸引是性吸引存在但很弱、很少，或分不清那算不算 |
| Demisexual | 半性吸引是灰色性吸引伞下的一个子类，指只有建立深厚情感连接之后才会有性吸引 |
| Allosexual | 有性吸引者的体验方式不在无性吸引光谱之内；灰色性吸引仍在这把伞下面 |
| Quoisexual | 困惑性吸引讲的是分不清，或觉得概念不适用；灰色性吸引讲的是性吸引少、弱或不确定。两者可以同时出现 |

**常见误解**

- **"灰色性吸引就是没想清楚的无性吸引。"** 灰色性吸引是一个独立的说法。有人会长期用这个词，也有人不用。
- **"灰色性吸引一定有条件。"** 有没有条件因人而异。条件型只是伞下的一类，例如 demisexual。
- **"灰色性吸引只是比无性吸引多一点性吸引。"** 灰色性吸引讲的是性吸引少、弱，或不确定，并不是按强弱排一个高低。

### 社区定义

对灰色这一段的边界，社群的看法不完全一样：有人只把"很少、很弱"算进来，也有人把"不确定那算不算"算进来。这个测试两种都包括。

中文通行译名是"灰性恋""灰色无性恋"。这个测试从 2026 年 11 月起改以"灰色性吸引"为主名，和无性吸引、无性吸引光谱用同一套说法；这是本测试的拟名，旧叫法照常列出，说的是同一件事。

## Demisexual

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `demisexual` |
| 英文名 | Demisexual |
| 中文名 | 半性吸引（拟） |
| 别名 | 半性恋（通行译名） |
| 层级 | 子类（条件型） |
| 上位类 | Grey-asexual / Greysexual |
| 对应的轴 | ③ 触发条件 |
| 共识度 | 高 |
| 测试适配度 | B |
| 来源 | 主树通用词；逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 也常译作「半性恋」，指只有在与某人建立深厚的情感连接之后，才可能对其产生性吸引的人。关键在于吸引本身需要连接才会出现，而不是"愿意发生性关系"需要连接。

### 核心特征

- 性吸引要等情感连接建立起来才可能出现：先有情感上的亲近，之后才可能有性吸引
- 情感连接的深浅因人而异，这个词不规定要多久、要达到什么程度
- 说的是"吸引要不要等连接"，不是"愿不愿意发生性关系"，后者是另一件事
- 这里的连接指深厚的情感连接，不一定是恋爱关系

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 半浪漫倾向（Demiromantic） | 同样需要先有情感连接，但讲的是浪漫吸引。两者可以同时出现，也可以只有一种 |
| Grey-asexual / Greysexual | 灰色性吸引是伞，半性吸引是伞下的一个子类，指需要条件的那一种 |
| Recipsexual | 互惠性吸引需要先知道对方对自己有性吸引；半性吸引需要先有深厚的情感连接。两种条件不同 |
| Asexual | 无性吸引指很少或从不体验性吸引；半性吸引在情感连接之后会有性吸引，只是需要这个条件 |

**常见误解**

- **"半性吸引就是只对很熟的人才有性方面的想法。"** 这个词讲的是情感连接，不是熟不熟。两者不完全一样。
- **"半性吸引一定要恋爱之后才有性吸引。"** 连接不一定是恋爱关系，它指的是深厚的情感连接；和是否恋爱是两回事。
- **"半性吸引的人对性一定保守。"** 对性的态度因人而异，和吸引需要什么条件没有直接关系。

## Recipsexual

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `recipsexual` |
| 英文名 | Recipsexual / Reciprosexual |
| 中文名 | 互惠性吸引（拟，与浪漫侧对齐） |
| 别名 | reciprosexual |
| 层级 | 子类（条件型） |
| 上位类 | Grey-asexual / Greysexual |
| 对应的轴 | ③ 触发条件 |
| 共识度 | 中 |
| 测试适配度 | B |
| 来源 | 主树通用词；逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 只有在知道对方对自己也有性吸引之后，才可能对对方产生性吸引的人。

### 核心特征

- 性吸引要等对方先有意才会出现，对方的心意是这里的关键条件
- 这里讲的是"得知对方有意"，并不限定是怎样得知的
- 它是条件型的一种，和半性吸引的条件不同：一个看情感连接，一个看对方有没有意思
- 吸引是在知道对方有意之后才出现的，是回应式的

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 单向性吸引（Akoisexual） | 单向性吸引是有吸引但不希望被回应；互惠性吸引是要先知道对方有意才会有吸引。两者方向不同 |
| 半性吸引（Demisexual） | 半性吸引需要情感连接，互惠性吸引需要知道对方有性吸引。两种条件可以同时符合 |

**常见误解**

- **"互惠性吸引的人不敢主动。"** 这个词讲的是吸引的条件，不是主动性或胆量。
- **"互惠性吸引的人只能和对方在一起。"** 这个词讲的是吸引的条件，和怎样相处、要不要建立关系没有直接关系。

### 社区定义

英文有两种拼法，Recipsexual 与 Reciprosexual 指的是同一个词。中文名是按浪漫侧的译法拟的，社群里还没有通行的中文叫法。

## Fraysexual

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `fraysexual` |
| 英文名 | Fraysexual |
| 中文名 | 磨损性吸引（拟） |
| 别名 | ignotasexual；磨散无性吸引（社群叫法） |
| 层级 | 子类（条件型） |
| 上位类 | Grey-asexual / Greysexual |
| 对应的轴 | ③ 触发条件 |
| 共识度 | 中 |
| 测试适配度 | B |
| 来源 | 主树通用词；逐条来源待补；别名、核心特征和误解取自社群流传资料（未另找到出处） |
| 完成度 | 完整 |

### 通俗释义

> 性吸引主要指向还不太熟悉的人，随着了解加深而减弱的人。它和半性吸引的方向相反。

### 核心特征

- 吸引主要出现在和对方还没有情感纽带的时候，比如刚认识、还不太了解
- 和对方形成情感纽带后，对这个人的性吸引会减弱或消失
- 什么算纽带、要多深才会消退，因人而异：有人刚知道对方的名字就淡了，有人要深入了解之后，也有人是进入浪漫关系之后；可以突然消失，也可以慢慢淡掉
- 和半性吸引方向相反：半性吸引是建立了深厚连接才有吸引，磨损性吸引是了解越多吸引越淡

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 半性吸引（Demisexual） | 方向相反：半性吸引在建立连接之后才会有性吸引，磨损性吸引在了解之后吸引会减弱 |
| 新鲜感消退 | 一般的新鲜感过去，讲的是情感或兴趣的变化；磨损性吸引讲的是对特定对象的性吸引随了解而变弱 |
| 害怕承诺 | 磨损性吸引讲的是吸引随了解的变化，不是对承诺的态度，两者是不同的事 |

**常见误解**

- **"磨损性吸引就是对人没兴趣，或只图新鲜。"** 它描述的是性吸引随了解而变化，不是对人整体的评价，也不是对新鲜感的追求。
- **"磨损性吸引的人一定害怕承诺。"** 这个词不描述对承诺的态度。
- **"一开始一定要很有感觉。"** 这个词只讲吸引主要出现在还不熟悉的时候，并不规定强度。
- **"吸引一定是慢慢变淡的。"** 消退的节奏因人而异，可以是突然消失，也可以随着纽带变深逐渐减弱。

## Akoisexual

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `akoisexual` |
| 英文名 | Akoisexual / Lithsexual |
| 中文名 | 单向性吸引（拟） |
| 别名 | lithsexual |
| 层级 | 子类（回应型） |
| 上位类 | Grey-asexual / Greysexual |
| 对应的轴 | ④ 回应与互惠 |
| 共识度 | 中 |
| 测试适配度 | B |
| 来源 | 主树通用词；逐条来源待补 |
| 完成度 | 完整 |

### 通俗释义

> 会体验性吸引，但不希望被对方回应，或者被回应之后吸引就消退的人。

### 核心特征

- 会对某个具体的人有性方面的吸引，这一点和有性吸引者相似
- 对"被回应"这件事有自己的态度：可能不希望对方有同样的回应
- 也可能是被回应、或进入关系之后，吸引就消退、失去兴趣
- 说的是对回应的态度，不是有没有吸引

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 无性吸引（Asexual） | 无性吸引是很少或从不体验性吸引；单向性吸引有性吸引，只是不希望被回应，或被回应后消退 |
| 互惠性吸引（Recipsexual） | 互惠性吸引要先知道对方有意，才会有吸引；单向性吸引是有吸引，却不希望对方回应。两者方向不同 |
| 被欲性恋（Disakoisexual） | 被欲性恋是希望被别人吸引，自己却无法回应；单向性吸引是自己有吸引，却不希望对方回应。两者方向相反 |

**常见误解**

- **"单向性吸引就是暗恋。"** 不一定。这个词讲的是对回应的态度，不一定是藏着不说的暗恋。
- **"不希望被回应，就是不喜欢对方。"** 吸引和不希望被回应可以同时存在，这个词讲的正是这一点。
- **"单向性吸引的人不会谈恋爱。"** 这个词讲的是性吸引和回应，和是否恋爱没有直接关系。

### 社区定义

社群里有人只用其中一种情况来理解这个词：有人指"不希望被回应"，有人指"被回应或进入关系后消退"，也有人两种都算。这个测试两种都包括。

| 现实＋虚拟角色性吸引（Semifictosexual） | 对虚构角色和现实中的人都有性吸引 |
| 真实角色性吸引（Veritasexual） | 虚拟角色性吸引的反义词，指性吸引的对象是真实的人 |

**常见误解**

- **"喜欢某个角色或作品，就是虚拟角色性吸引。"** 喜欢某个角色，不等于性吸引指向这个角色。要看的是性吸引的指向。
- **"虚拟角色性吸引就是不正常的幻想。"** 这个词讲的是吸引指向的对象，不评价幻想本身。
- **"虚拟角色性吸引一定属于无性吸引光谱。"** 是否属于光谱有争议，不能单凭这个词推出。

### 社区定义

这个词的来源包括学术研究和社群资料，对它是否属于无性吸引光谱，两边的看法并不一致：有的社群资料把它直接算作无性吸引光谱里的一类，也有人认为要看本人的整体体验。研究上也有人讨论过对虚构角色的爱与欲望。

中文里，对动漫角色的性吸引和对虚构角色的性吸引，都被叫作虚拟角色性吸引。在东亚，尤其是日语语境里与“二次元”相关的人群，有自己的亚文化圈。

- **"美感性恋只属于无性吸引者。"** 这个词多见于无性吸引者，但不限于无性恋社群。

### 社区定义

这个词多见于无性恋社群，但不限于那里。有人把它归在 sex-ambivalent 伞下。

这个词在 2017 年 10 月之前就已经出现，造词者不明。词根 bellus 来自拉丁语，意思是漂亮。
