## Adexsexual

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `adexsexual` |
| 英文名 | Adexsexual |
| 中文名 | 抽象性恋（拟） |
| 别名 | — |
| 层级 | 延伸区（对象） |
| 上位类 | Ace-spec |
| 对应的轴 | ⑦ 对象类型与可及性，联动 2A、2C |
| 共识度 | 低或有分歧（延伸区） |
| 测试适配度 | C |
| 来源 | Reddit 原始讨论、AVEN 说明帖；已核实；新旧两版用法见附录 B |
| 完成度 | 完整 |

### 通俗释义

> 不对真实、具体的人产生性吸引，但会对想象中的性体验或感受有欲望或唤起的人。一旦把想象聚焦到某个具体的人身上，这种欲望就会减弱或消失。

### 核心特征

- 性方面的想象可以有，而且可能带着欲望或身体上的唤起
- 这些欲望指向想象中的抽象情境，没有具体的、真实存在的对象
- 当想象落到一个具体的人身上，欲望会减弱或消失
- 重点是区分两件事：幻想里的欲望，和对现实中具体的人的性吸引

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 纸性恋（Fictosexual） | 纸性恋的对象是虚构角色；抽象性恋的对象是抽象、非特定的想象 |
| 遥远性恋（Proculsexual） | 遥远性恋的对象是有具体身份、但明知无法建立关系的人；抽象性恋的想象没有这样一个具体的人 |
| 旁观性恋（Aegosexual） | 旁观性恋讲的是自己是否渴望作为当事人参与；抽象性恋讲的是幻想中的欲望与具体对象的关系。两者可以同时出现 |

**常见误解**

- **"幻想越多，就是抽象性恋。"** 这个词讲的是欲望指向哪里，幻想多少不决定归属。
- **"幻想里有欲望，就等于对现实中的人也有性吸引。"** 这两件事不一样，抽象性恋正是讲这一点的。

### 社区定义

这个词有两种用法。较早的用法是"幻想中有吸引、现实中消退"，现在的定义把幻想里的欲望和对具体对象的性吸引分开。两种用法不完全一样。

### 核心特征

- 性吸引指向的对象是自己
- 可以只对自己有，也可以同时对别人有
- 这个词讲的是吸引指向谁，不说明行为，也不说明要不要和别人发生关系
- 树里把它放在 ace-spec 下面只作导航，是否属于光谱要看整体的体验

### 概念边界

| 旁观性恋（Aegosexual） | 旁观性恋讲的是自己是否渴望作为当事人参与；自我性恋讲的是吸引指向自己 |

- **"自我性恋就是自恋。"** 这个词讲的是吸引指向谁，不评价一个人的性格或自尊心。
- **"对自己有性吸引，就不能对别人有。"** 两者可以同时存在。
- **"自我性恋一定属于无性恋光谱。"** 树里放在那一侧只作导航，是否属于光谱不能单凭这个词推出。

| 完成度 | 完整 |

### 通俗释义

> 性吸引主要或只指向虚构角色的人。是否属于无性恋光谱存在争议，这个词本身不决定归属。

### 核心特征

- 性吸引的对象是小说、动漫、游戏、影视等作品里的虚构角色
- 对现实中的人，性吸引很少或没有
- 这个词讲的是对象是谁，不说明吸引的强弱或频率
- 是否属于无性恋光谱，不同人的看法不同，由本人判断

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 虚拟浪漫倾向（Fictoromantic，浪漫侧） | 虚拟浪漫倾向讲的是浪漫吸引指向虚构角色；纸性恋讲的是性吸引指向虚构角色。两者可以同时出现 |
| 遥远性恋（Proculsexual） | 遥远性恋的重点是明知无法建立现实关系，对象可以是虚构角色，也可以是现实中的人；纸性恋的重点是对象是虚构的 |
| 抽象性恋（Adexsexual） | 抽象性恋的对象是抽象、非特定的想象；纸性恋的对象是有名字、有形象的虚构角色 |

**常见误解**

- **"喜欢某个角色或作品，就是纸性恋。"** 喜欢某个角色，不等于性吸引指向这个角色。要看的是性吸引的指向。
- **"纸性恋就是不正常的幻想。"** 这个词讲的是吸引指向的对象，不评价幻想本身。
- **"纸性恋一定属于无性恋光谱。"** 是否属于光谱有争议，不能单凭这个词推出。

### 社区定义

这个词的来源包括学术研究和社群资料，对它是否属于无性恋光谱，两边的看法并不一致。研究上也有人讨论过对虚构角色的爱与欲望。

## Disakoisexual

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `disakoisexual` |
| 英文名 | Disakoisexual |
| 中文名 | 被欲性恋（拟） |
| 别名 | — |
| 层级 | 延伸区（回应） |
| 上位类 | Ace-spec |
| 对应的轴 | ④ 回应与互惠（希望被吸引，自己无法回应） |
| 共识度 | 低或有分歧（延伸区） |
| 测试适配度 | C |
| 来源 | 个人身份整理页；已核实（附录 B） |
| 完成度 | 完整 |

### 通俗释义

> 希望别人对自己产生性吸引，但自己没办法以相应的性吸引来回应的人。

### 核心特征

- 希望被别人吸引，这是这个词的方向
- 自己对别人的回应，没办法做到同样的性吸引
- 讲的是回应的方向，不是对性本身的态度
- 希望被吸引，和自己有没有性吸引，是两件事

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 单向性恋（Akoisexual） | 单向性恋是自己有性吸引，却不希望被回应；被欲性恋是希望被别人吸引，自己却无法回应。两者方向相反 |
| 互惠性恋（Recipsexual） | 互惠性恋讲的是吸引要先知道对方有意；被欲性恋讲的是希望被别人吸引、而自己无法回应 |
| 无性恋（Asexual） | 无性恋讲的是自己很少或从不体验性吸引；被欲性恋的重点是希望被别人吸引。两者可以同时出现 |

**常见误解**

- **"被欲性恋就是缺爱，想被人喜欢。"** 这个词讲的是对性吸引的回应方向，不说明原因，也不判断一个人的需要。
- **"被欲性恋一定想要恋爱或发生性关系。"** 这个词只讲吸引的方向，不规定关系的形式。

**常见误解**

- **"迷惑性恋就是没想清楚自己是不是无性恋。"** 这个词讲的是不理解性吸引这个概念，这本身是一种体验，不需要被纠正。
- **"迷惑性恋的人一定没有性吸引。"** 这个词讲的是概念上的困惑，不直接说明有没有性吸引。

### 通俗释义

> 只对自己明知无法和其建立现实关系的人产生性吸引的人。重点在于本人心里认定"不可能"，而不只是距离远。

### 核心特征

- 性吸引只出现在自己明知不可能建立现实关系的对象身上，比如名人、虚构角色，或现实中明知没有可能的人
- 这份吸引可以是持续而强烈的，不只是偶尔想到一下
- 重点在本人认定的"不可能"，不在地理上的远近

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 纸性恋（Fictosexual） | 纸性恋的对象是虚构角色；遥远性恋的对象可以是现实中有身份、却明知无法建立关系的人，也可以是虚构角色。两者可以重叠 |
| 抽象性恋（Adexsexual） | 抽象性恋的想象没有具体的对象；遥远性恋的对象是有具体身份、只是明知无法建立关系的人 |
| 异地恋 | 异地恋讲的是双方相隔多远；遥远性恋讲的是本人认定无法建立关系的对象 |

**常见误解**

- **"只要对方不可能和自己在一起，就是遥远性恋。"** 这个词讲的是持续而强烈的性吸引，偶尔一次的想象不属于这个词。
- **"遥远性恋就是单相思。"** 这个词讲的是对象的可及性和吸引的性质，不是单方面的情感。

### 社区定义

这个词在 Orientando 的词条里有两种用法：较早的只看距离，后来的看本人是否明知无法建立关系。这个测试用后一种。

## Pseudosexual

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `pseudosexual` |
| 英文名 | Pseudosexual |
| 中文名 | 伪性恋（拟） |
| 别名 | — |
| 层级 | 延伸区（成分） |
| 上位类 | Ace-spec |

| 共识度 | 低或有分歧（延伸区） |
| 测试适配度 | C |
| 来源 | AVEN 2022-01-23 造词讨论；已核实 |
| 完成度 | 完整 |

### 通俗释义

> 审美、感官等其他吸引模仿或接近性吸引的样子，可能伴随性方面的唤起，却缺少针对对方的性行为驱动力的体验。

### 核心特征

- 有一种很像性吸引的感觉，但它其实来自审美、感官等其他吸引
- 可能伴随性方面的唤起，但不是想和对方发生性行为那种驱动
- 也可能是其他吸引遮盖了性吸引，或者一时分不清这种体验属于哪一类
- 这些体验不需要先把所有的不确定都排除掉

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 审美吸引 | 审美吸引是欣赏对方的外貌或美感；伪性恋讲的是这种欣赏看起来像性吸引 |
| 感官吸引 | 感官吸引是想要非性的身体接触；伪性恋讲的是感官等其他吸引看起来像性吸引 |
| 困惑性恋（Quoisexual） | 困惑性恋讲的是分不清或不适用；伪性恋可以是分不清，也可以是其他吸引在模仿性吸引。两者可以重叠 |

**常见误解**

- **"伪性恋就是假的性吸引。"** 它描述的是来源不同、看起来像性吸引的感受；感受本身是真实的。
- **"伪性恋的人是在骗自己。"** 这个词只描述感受的来源和样子，不判断一个人是否诚实或心理状态。
- **"只要觉得像性吸引，就是伪性恋。"** 这个词讲的是其他吸引模仿或遮盖性吸引的情形，是否属于它由本人判断。

### 社区定义

这个词出自 AVEN 2022 年的一次造词讨论。之后的说法把"其他吸引遮盖性吸引"和"分不清类别的体验"也纳入。

- **"错位性恋就是没有性吸引。"** 这个词的前提是确实有性吸引，只是觉得不自然。
- **"错位性恋的人一定要改变这种感觉。"** 这个词只描述感受，不要求改变，也不替本人判断要不要处理。

### 通俗释义

> 无性恋光谱上的一种吸引：没有完整的性吸引，可能有视觉吸引或其他形式的吸引。对某个特定的人，可能会欣赏，也有唤起，但不想与其发生性关系；吸引到这一步就结束了。

### 核心特征

- 不是完整的性吸引，但可能有视觉吸引或其他形式的吸引
- 对某个特定的人，可能欣赏、有唤起，却不想和对方发生性关系

### 概念边界

**相似的标签**

| 标签 | 区别 |

- **"终止性恋就是完全没有吸引。"** 它描述的是吸引停在欣赏和唤起这一步，可能仍然有视觉吸引或其他形式的吸引。

- **"终止性恋一定是对性的排斥。"** 这个词讲的是吸引的完整程度，不描述对性的态度。

### 社区定义

这个词在 2021 年 9 月被造出。词根 desino 来自拉丁语，意思是离开或停止。

### 基本信息

### 通俗释义

> 只有在初次见面时就已经产生的性吸引才会存在的人。这种感觉有点像"一见钟情"，之后不会从无到有地产生。

### 核心特征

- 性吸引的产生时间是重点：只有初见时就有的，才属于这个词
- 对还不太了解的人也可能有性吸引，这种吸引可能转瞬即逝，也可能不够强，不足以发展成关系

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 半性恋（Demisexual） | 两者方向相反：半性恋要先建立深厚的情感连接才会有性吸引，初遇性恋则要在初次见面时就已经有 |
| 磨损性恋（Fraysexual） | 磨损性恋讲的是性吸引随着了解而减弱；初遇性恋讲的是吸引在初见时是否已经产生。两者可以同时符合 |
| 一见钟情 | 一见钟情多指浪漫方面的心动；初遇性恋讲的是性吸引，两者不是同一件事 |

**常见误解**

- **"初遇性恋就是对第一次见面的人都有性吸引。"** 这个词讲的是吸引是否在初次见面时产生，并不是每个人初见都会有。
- **"只要见过一面，就是初遇性恋。"** 必须是初见时就已经有的吸引，之后才出现的，不属于这个词。
- **"初遇性恋的吸引一定很强烈。"** 吸引可能转瞬即逝，也可能不够强，不足以发展成关系。

### 社区定义

这个词出自 Reddit 上的一条讨论。和它相近的说法有单向性恋、磨损性恋，它们都讲性吸引在什么情况下出现或消失。

词根 coeo 来自拉丁语，意思是相遇、结合。

## Apothisexual

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `apothisexual` |
| 英文名 | Apothisexual |
| 中文名 | 排斥性恋（拟） |
| 别名 | — |

### 通俗释义

> 对性感到排斥的人，这个词是"性排斥"的另一种说法，常被无性恋的人用来描述自己。

### 核心特征

- 对性感到排斥：想到性或参与性行为时，会有强烈的不适或抗拒
- 排斥的对象可能是自己参与性行为，也可能是性这件事的整体
- 有的人只排斥自己参与，对不涉及自己的性活动没有排斥
- 这类排斥通常让人不寻求性关系

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 无性恋（Asexual） | 无性恋讲的是性吸引很少或从不；排斥性恋讲的是对性感到排斥。两者常一起出现，讲的是不同的事 |
| 性排斥（sex-repulsed） | 两者指的是同一种感受。排斥性恋是这种感受的一个说法，用不用由本人决定 |
| 排斥浪漫倾向（Apothiromantic，浪漫侧） | 浪漫侧的对应说法，讲的是对浪漫感到排斥。两者可以同时有 |

**常见误解**

- **"排斥性恋就是讨厌别人。"** 这个词讲的是对性的排斥，不是对人的厌恶。
- **"排斥性恋的人都排斥所有亲密关系。"** 这个词讲的是对性的排斥；对其他亲密方式的态度，是另外的事。
- **"对性排斥就一定要处理。"** 这个词只描述感受，不判断对错，也不替本人决定要不要处理。

### 社区定义

和排斥浪漫倾向都符合的人，有时用 apothi aroace 这个组合说法。词根 apothi 来自希腊语 apothisan，意思是排斥。
