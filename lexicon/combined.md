# 名词库 · 组合标签与总伞

浪漫和性两条光谱合起来看时用的词，方向模块里与第三吸引相关的两个 aroace 标签，以及讲吸引拆分方式的 SAM。说明见 02 的第 5 节和 3.6，格式见 [README](README.md)。

## Aspec

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `aspec` |
| 英文名 | Aspec |
| 中文名 | 无性恋／无浪漫光谱（AUREA 中文版） |
| 别名 | a-spec、A谱系（AUREA 简体中文版）、無性戀／無浪漫光譜（AUREA 繁体中文版） |
| 层级 | 总伞 |
| 上位类 | — |
| 对应的轴 | 维度一、二整体 |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | AUREA 中文基本术语（简体、繁体）；已核实 |
| 完成度 | 完整 |

### 通俗释义

> aro-spec 与 ace-spec 的总称：只要浪漫或性其中一边落在光谱内，就在 aspec 范围内；部分语境还包括 aplatonic

### 核心特征

- 是最上位的总伞，下面是浪漫（aro-spec）和性（ace-spec）两把伞
- 只要其中一边在光谱内就算，两边都在也算
- 多用来指一群人，比如"aspec 社群"；介绍自己时，很多人会用更具体的词，比如 aroace、demiromantic
- 包不包括 aplatonic，各来源说法不一

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Aroace | aroace 要求浪漫、性两边都在光谱内；aspec 只要一边就够 |
| Asexual / Ace-spec | 中文里常把"无性恋"当作总称来用，但 aspec 还包括有性吸引的 aro-spec 的人（alloaro） |
| Aro-spec | aro-spec 只是 aspec 下的其中一把伞 |
| 分离吸引模型（SAM） | SAM 是把浪漫和性分开描述的思路；aspec 这个词本身就建立在这种拆分上。不使用 SAM 的人，也可以按自己的方式认同 aspec |

**常见误解**

- **"aspec 就是无性恋。"** aspec 也包括会被人在性的意义上吸引、但浪漫吸引很少的人。
- **"aspec 是一个统一的身份，大家体验都一样。"** 它是一个范围的说法，伞下的人体验差别很大，也有人不用这个词。
- **"aspec 一定包括 aplatonic。"** 有的人算，有的人不算，没有统一的说法。
- **"aspec 的人都不想要亲密关系。"** 吸引和想要什么样的关系是两件事；关系偏好在维度四、五单独看。

### 社区定义

aspec 是 aro 和 ace 社群共用的最上位说法，用来指"在浪漫或性吸引上不按主流方式体验的人"这一整群人。有的人把 aplatonic（很少或不体验柏拉图吸引）也算进 aspec，有的人不算。

## Aroace

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `aroace` |
| 英文名 | Aroace |
| 中文名 | 无浪漫倾向无性恋（社群流传） |
| 别名 | aro ace、aro-ace、无浪漫无性恋（社群流传）、無性戀無浪漫（AUREA 繁体中文版） |
| 层级 | 节点 |
| 上位类 | Aspec |
| 对应的轴 | aro-spec × ace-spec |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | AUREA 简体中文基本术语（释为"无浪漫吸引无性吸引者"的简称）；社群科普：豆瓣小组帖、微博科普文、中文维基 |
| 完成度 | 完整 |

### 通俗释义

> 浪漫吸引和性吸引两边都落在光谱内的人：很少或不体验这两种吸引，或者以非典型的方式体验它们

### 核心特征

- 在浪漫和性两个方向上都不按主流方式体验吸引，两边都要算进去
- 两边的程度和形态各自不同，不必一样
- 有人把它当作一个整体身份来认同，而不只是"无浪漫"和"无性"两个标签相加

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Aromantic | 只说浪漫这一边。如果性吸引是主流方式，那是 alloaro，不是 aroace |
| Asexual / Ace-spec | 只说性这一边。如果浪漫吸引是主流方式，那是 alloace，不是 aroace |
| Aspec | aspec 只要一边在光谱内就够；aroace 要求两边都在 |
| Alloaro / Alloace | 两者各只有一边在光谱内，和 aroace 正好相反 |

**常见误解**

- **"aroace 就是冷漠、没有感情。"** 吸引讲的是会不会对特定的人产生某种感觉，不讲有没有感情。很多 aroace 很珍视朋友、家人，也可能有深厚的情感联结。
- **"aroace 一定不想要任何关系。"** 吸引和想要什么关系是两件事。有人不体验吸引，但想要伴侣式关系或 QPR；关系偏好在维度四、五单独看。
- **"没有谈过恋爱、没有过性经验，就是 aroace。"** 这个词讲的是吸引，不是行为或经历。是否有过相关经历，不决定一个人是不是 aroace。

### 社区定义

aroace 常被当作一个整体身份来认同，而不只是把"无浪漫"和"无性"两个标签相加。它的中文叫法也不统一，别名里列的几种都在社群里出现过。

## Alloaro

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `alloaro` |
| 英文名 | Alloaro |
| 中文名 | 有性恋无浪漫倾向（AUREA 中文版） |
| 别名 | allo aro、aro allo（AUREA 简体中文版）、allosexual aromantic |
| 层级 | 节点 |
| 上位类 | Aspec |
| 对应的轴 | aro-spec × allosexual |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | AUREA 简体中文基本术语（释为"有性吸引无浪漫吸引者"的简称）；繁体中文版作"有性戀無浪漫"；已核实 |
| 完成度 | 完整 |

### 通俗释义

> 对别人有性吸引，但浪漫吸引很少或不以主流方式体验的人

### 核心特征

- 性这一边按主流方式体验：会对特定的人产生性吸引
- 浪漫这一边在 aro-spec 内：很少或不体验浪漫吸引，或以非典型方式体验
- 两件事分开看：有性吸引，不等于浪漫吸引也多
- 与 aroace 的区别只在性这一边

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Aroace | 两边都在光谱内，性吸引也很少或不体验；alloaro 的性吸引是主流方式 |
| Allosexual（有性恋） | 只说性这一边。浪漫这一边不在 aro-spec 内，就不是 alloaro |
| Aromantic | 只说浪漫这一边；alloaro 的人在性这一边有性吸引 |
| Alloace | 两边正好相反：浪漫吸引是主流方式，性吸引很少或不体验 |

**常见误解**

- **"alloaro 只想要性，不要感情。"** 有性吸引不等于只看重性。想要什么样的关系是另外一回事，关系偏好在维度四、五单独看。
- **"有性吸引，就是性欲很强。"** 吸引和性欲是两件事。性欲在测试里单独问，不由这个词决定。

### 通俗释义

> 对别人有浪漫吸引，但性吸引很少或不体验（或以非典型方式体验）的人

### 核心特征

- 浪漫这一边按主流方式体验：会对特定的人产生想"在一起"的感觉
- 性这一边在 ace-spec 内：很少或不体验性吸引，或以非典型方式体验
- 两件事分开看：有浪漫吸引，不等于会有性吸引

### 概念边界

**相似的标签**

**常见误解**

- **"alloace 是还没有过性经验的人。"** 这个词讲的是吸引，不是经历。是否有过性经验，不决定是不是 alloace。

## Oriented aroace

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `oriented-aroace` |
| 英文名 | Oriented aroace |
| 中文名 | 第三吸引力型无浪漫无性恋（AUREA 中文版） |
| 别名 | 定向无浪漫无性吸引（AUREA 简体中文版）、第三吸引力型無浪漫無性戀（AUREA 繁体中文版） |
| 层级 | 节点（方向模块，延伸区） |
| 上位类 | Aroace |
| 对应的轴 | 1D、2E 方向 × 维度三 |
| 共识度 | 中 |
| 测试适配度 | C（由参与者选择，不自动输出） |
| 来源 | AUREA 英文完整术语表（原始用法）；AUREA 简体中文身份术语（"定向无浪漫无性吸引"）；AUREA 繁体中文身份用语 |
| 完成度 | 完整 |

### 通俗释义

> 浪漫吸引和性吸引都很少或不体验，但有某种既不属于浪漫也不属于性的吸引，对自己的身份和 aroace 同样重要

### 核心特征

- 前提是 aroace：浪漫和性两边都很少或不体验
- 另外有一种第三吸引（如柏拉图、感官、审美或别样吸引，见维度三），对身份重要
- 这种吸引与 aroace 身份同等重要，两者并列

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Aroace | aroace 只要求两边都在光谱内；oriented 在此之上，还要求有一种对身份重要的第三吸引 |
| Angled aroace | oriented 只面向浪漫和性都不体验的人；angled 的范围更宽，包括灰色、半浪漫等倾向 |
| 第三吸引（tertiary attraction） | 第三吸引是各种其他吸引的统称；oriented 是把某一种第三吸引和身份绑在一起的说法 |
| 常规方向（如双性浪漫） | 方向说的是浪漫或性吸引指向哪一类人；oriented 说的是第三吸引。两者可以并用，如 bi oriented aroace |

**常见误解**

- **"只要和 aroace 并用某个方向，就是 oriented aroace。"** 不能单凭标签组合得出，是否采用这个词，由本人选择。
- **"oriented aroace 是有浪漫或性吸引、但比较少的人。"** 它说的是有一种第三吸引对身份重要，不是浪漫或性吸引的多少。

### 社区定义

这个词有两种中文叫法，都来自 AUREA：繁体的"第三吸引力型无浪漫无性恋"和简体的"定向无浪漫无性吸引"。AUREA 的说明里，它是为从未体验过浪漫或性吸引的人设立的。是否采用由本人决定，测试只展示定义，不替人裁定身份。

| 完成度 | 完整 |

### 通俗释义

> 在无浪漫或无性恋的光谱上（包括灰色、半浪漫、半性恋等倾向），同时体验到某种与浪漫和性都无关的吸引，而且这种吸引对自己的身份同样重要

### 核心特征

- 和 oriented 的主要区别在适用范围：angled 不限于浪漫和性都不体验的人，只要自己处在无浪漫或无性恋的光谱上就可以，无论是浪漫一边、性一边，还是两边都在
- 第三吸引指的是某种与浪漫和性都无关的吸引，如柏拉图、感官、审美或别样吸引（见维度三）
- 这种吸引对身份重要，与光谱上的身份并列

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Oriented aroace | oriented 只面向浪漫和性都不体验的人；angled 只要求在光谱上，范围更宽 |
| Aroace | aroace 要求浪漫和性两边都在光谱内；angled 不要求两边都在，但要求一种对身份重要的第三吸引 |
| Grey- / Demi- 等 | 灰色、半浪漫等是 angled 可以包括的光谱倾向，但它们本身不说明第三吸引 |
| 第三吸引（tertiary attraction） | 第三吸引是统称；angled 是把某种第三吸引和光谱身份并列的说法 |

**常见误解**

- **"用了 pan 等标签，就是 angled aroace。"** 不单凭标签组合得出，是否采用这个词，由本人选择。
- **"只要有某种第三吸引，就是 angled aroace。"** 这个词同时要求：这种吸引对身份重要，并且本人处在无浪漫或无性恋的光谱上。

### 社区定义

这个词的适用范围和个人使用会有差异：有人只在浪漫或性某一边的光谱上用，也有人两边都在光谱上。测试只展示定义，由参与者自己判断是否采用，不替其裁定身份。

## Split attraction model

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `split-attraction-model` |
| 英文名 | Split attraction model |
| 中文名 | 分离吸引模型（AUREA 中文版） |
| 别名 | SAM |
| 层级 | 概念（不是身份标签） |
| 上位类 | — |
| 对应的轴 | Q0-02 作答方式：拆分 / 不拆分 |
| 共识度 | 中 |
| 测试适配度 | —（不作结果；"不拆分"只作说明，不写进结果名称） |
| 来源 | AUREA 简体中文基本术语（SAM 词条）；已核实 |
| 完成度 | 完整 |

### 通俗释义

> 一种把不同的吸引体验分开、各自标记的描述方式，例如把浪漫吸引和性吸引分开看

### 核心特征

- 把吸引按不同特征分成几种类型，每一种当作独立的体验
- 每种吸引可以分别标记，不要求彼此一致
- 它是描述吸引的方式，不是身份。用或不用，不改变一个人实际的吸引体验

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 不拆分（作答方式） | 觉得浪漫和性混在一起、很难分清的人，可以在测试开场选这一项（能分清、只是觉得拆开没什么意义的，仍按拆分作答）。选了之后，结果呈现整体的吸引体验，不分别推出 aro、ace 归属，也不拼组合标签（见 02 第 5 节） |
| Aspec | aspec 的划分建立在"浪漫、性可以分开看"的前提上；SAM 则是具体的拆分方法。两者不是同一个东西 |

**常见误解**

- **"用 SAM 的人一定是 aspec。"** SAM 只说明吸引怎样分开描述。是否落在 aspec 光谱内，要看拆开后每一边的体验。
- **"不拆分，就是没有吸引。"** 不拆分只是作答方式：答的是整体的吸引体验，并不表示没有吸引。
- **"SAM 适用于每一个人。"** AUREA 的说明是它不适用于描述每个人的经历。

### 社区定义

AUREA 的说明里提到，这个模型的历史也存在部分争议，所以它只是一种可选的描述方式。
