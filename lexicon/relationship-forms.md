# 名词库 · 关系形态（维度四）

参与者想要的关系形态。分类树见 03 的 7.2，格式见 [README](README.md)。

本类九个词条已补齐。“伴侣式关系”“非伴侣式的重要关系”是这个测试为了整理答案设的分类，不是社群术语。FWB 是“以性为主的非浪漫关系”里的一种。Q4-01 的“未定／随缘”是作答状态，不是关系形态，不另立词条。

## QPR

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `qpr` |
| 英文名 | Queerplatonic relationship |
| 中文名 | 酷儿柏拉图关系（通行） |
| 别名 | QPR；伴侣称 QPP（酷儿柏拉图伴侣，AUREA 简体中文版），俗称 zucchini（西葫芦） |
| 层级 | 节点 |
| 上位类 | 伴侣式关系 |
| 对应的轴 | 4A 想要的关系形态；具体内容看 4B |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | AUREA 中文吸引与关系术语、AUREA 简体中文基本术语；已核实 |
| 完成度 | 完整 |

### 通俗释义

> 不以浪漫为核心（或拒绝用"浪漫/柏拉图"二分来定义），但在承诺、亲密、优先级或生活交织上超出社会对"友谊"的常规期待的关系。具体内容完全由当事人定义，可以包含也可以不包含肢体亲密、同居、性

### 核心特征

- 是一段关系，不是一种感觉：两个人彼此承诺、很亲近，重要程度超出了社会对"朋友"的默认设定
- 不以浪漫为核心，或者干脆不用"浪漫 / 柏拉图"来归类这段关系
- 关系里放什么（同居、拥抱、排他、一起养老……）由两个人商量，没有标准答案
- 起源于 aro 和 ace 社群，但谁都可以用

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 亲密友谊 / 承诺式友谊 | 区别在于当事人是否觉得这段关系"超出了友谊的常规"。同样的相处方式，有人叫亲密友谊，有人叫 QPR |
| 柏拉图伴侣 / 柏拉图式生活伴侣 | 很多人视为同义。区别通常在于是否有意打破"浪漫/柏拉图"的二分：柏拉图伴侣明确说自己是柏拉图式的，QPR 可以不归入任何一边 |
| 浪漫伴侣关系 | 浪漫伴侣关系以浪漫为核心；QPR 不以浪漫为核心。两者都可以有承诺、同居、肢体亲密 |
| Queerplatonic attraction | 酷儿柏拉图吸引是对某个人的感觉；QPR 是一段关系。有 QPR 的人不一定认为自己有这种吸引 |

**常见误解**

- **"QPR 就是没有性的恋爱。"** QPR 不以浪漫为核心，和有没有性无关：有的 QPR 包含性，很多恋爱也没有性。
- **"QPR 只是恋爱前的过渡阶段。"** QPR 本身就是一种完整的关系，不是等着"升级"的半成品。
- **"QPR 一定要同居、一定要排他。"** 内容完全由当事人定义，可以有，也可以没有。
- **"只有 aro 或 ace 的人才能有 QPR。"** 它起源于 aro 和 ace 社群，但任何想要这种关系的人都可以用。

### 社区定义

QPR 诞生于 aro 和 ace 社群，但不限于这些人：任何想要这种关系的人都可以用。基于别样吸引的关系通常也称为 QPR。俗称 zucchini 有人觉得亲切，也有人觉得幼稚，用不用由当事人决定。

## 伴侣式关系

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `partnership` |
| 英文名 | — |
| 中文名 | 伴侣式关系（本稿自设） |
| 别名 | — |
| 层级 | 伞（本稿归类用） |
| 上位类 | — |
| 对应的轴 | 4A |
| 共识度 | —（不是社群通用术语） |
| 测试适配度 | A（作为回退时的上位类） |
| 来源 | 本稿组织分类；非社群通用术语；分类参考 AUREA FAQ 对伴侣式关系的讨论 |
| 完成度 | 完整 |

### 通俗释义

> 这是这个测试用来整理答案的分类，不是社群术语：当事人愿意彼此视为伴侣、一起商量承诺和责任的关系，都算“伴侣式关系”。它可以是浪漫伴侣关系、QPR，也可以是柏拉图伴侣关系；具体亲密程度、是否同居、怎样承诺由当事人决定。

### 核心特征

- 强调当事人是否把彼此视为伴侣，不以恋爱为前提。
- 可以有长期承诺、彼此照顾或共同生活，具体安排没有固定模板。
- 浪漫关系、QPR 和柏拉图伴侣都可能采用伴侣身份。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 浪漫伴侣关系 | 是其中的一种；不是所有伴侣的默认形态。 |
| QPR / 柏拉图伴侣 | 也可能采用伴侣身份，但不要求属于浪漫关系。 |
| 非伴侣式的重要关系 | 亲密和承诺程度可能相近，关键看参与者如何定义关系。 |

**常见误解**

- **“伴侣必然等于恋人。”** 非浪漫的关系也可能采用伴侣身份。
- **“必须结婚、同居或排他才算。”** 这些都可以由当事人商量，不是伴侣式关系的门槛。

## 浪漫伴侣关系

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `romantic-partnership` |
| 英文名 | Romantic partnership |
| 中文名 | 浪漫伴侣关系 |
| 别名 | — |
| 层级 | 节点 |
| 上位类 | 伴侣式关系 |
| 对应的轴 | 4A |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | AUREA 英文 FAQ（浪漫关系由双方认定，可不依赖浪漫吸引）；AUREA 英文吸引与关系术语 |
| 完成度 | 完整 |

### 通俗释义

> 当事人将彼此的伴侣关系理解为浪漫关系，并愿意以恋爱／浪漫伴侣的方式相处。它可以包含情感亲密、浪漫表达和承诺，但不能由有没有性行为、是否结婚、是否牵手等某项行为单独决定。

### 核心特征

- 说的是当事人对一段关系的共同理解；浪漫吸引是另一项体验。
- 约会、亲吻、情话和纪念日可能是浪漫表达，但没有一项是绝对必要条件。
- 可以有承诺、共同生活或性互动，也可以不包含这些元素。
- 是不是排他、是否只有一位伴侣，由关系结构另行描述。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| QPR | 通常被理解为非浪漫关系，或不沿用恋爱／友谊二分；相处形式可能很像。 |
| 柏拉图伴侣 | 后者明确以非浪漫的方式认定伴侣身份。 |
| 浪漫吸引 | 吸引是对人的感受；浪漫关系是双方对关系的认定，不能相互代替。 |

**常见误解**

- **“没有浪漫吸引便不能恋爱。”** AUREA 指出无浪漫光谱者仍可能选择浪漫伴侣关系。
- **“浪漫伴侣一定有性或婚姻。”** 性与婚姻是独立的关系元素。

### 社区定义

AUREA 明确指出，即使一方属于无浪漫光谱、没有典型的浪漫吸引，只要双方愿意并认可关系的定位，也可以建立浪漫关系。

## 柏拉图伴侣

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `platonic-partnership` |
| 英文名 | Platonic partnership / Platonic life partner |
| 中文名 | 柏拉图伴侣 / 柏拉图式生活伴侣 |
| 别名 | — |
| 层级 | 节点 |
| 上位类 | 伴侣式关系 |
| 对应的轴 | 4A |
| 共识度 | 中 |
| 测试适配度 | B |
| 来源 | Oxford University LGBTQ+ Society（platonic partner）；AUREA FAQ（非浪漫伴侣与 QPR）；与 QPR 边界未统一 |
| 完成度 | 完整 |

### 通俗释义

> 当事人明确把彼此视为非浪漫的伴侣：可能一起照顾生活、承担承诺或规划未来，但不把这段关系称为恋爱。“柏拉图伴侣”强调非浪漫的伴侣身份，“柏拉图式生活伴侣”是更具体一些的说法。

### 核心特征

- 当事人认同是伴侣，同时明确不把这段关系定位为浪漫关系。
- 可能一起承担责任、作长期规划，也可以各自生活。
- 用柏拉图伴侣称呼，不自动规定性、肢体亲密或排他安排。
- 有些人会把类似关系称为 QPR，有些人更喜欢柏拉图伴侣。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| QPR | 两者有重叠；QPR 常强调超出友谊惯例或不采用浪漫／友谊二分，不能强制互斥。 |
| 亲密友谊 | 友谊也可以长期承诺，但未必采用伴侣身份。 |
| 浪漫伴侣关系 | 主要差别在关系是否被当事人定义为浪漫，而非是否同居或牵手。 |

**常见误解**

- **“这就是没有性的恋爱。”** 关键是当事人将关系定位为非浪漫；有无性互动是另一个问题。
- **“QPR 和柏拉图伴侣一定能客观分开。”** 社区中两种用法交叠，须尊重当事人的称呼。

### 社区定义

牛津大学 LGBTQ+ Society 用 platonic partner 称呼非浪漫关系里的伴侣。它和 QPR 有很多重叠，叫哪个名字要看当事人自己。名字里有“生活”，也不代表一定同居或共用财务。

| 来源 | 本稿组织分类；非社群通用术语；范围参照 AUREA FAQ、Chosen family 条目 |
| 完成度 | 完整 |

### 通俗释义

> 这是这个测试用来整理答案的分类，不是社群术语：指对当事人非常重要、可以有亲密、支持和长期照应，但没有被当事人定义为伴侣关系的联系，例如亲密友谊、选择的家人。

### 核心特征

- 关系可以深厚而稳定，不因未采用伴侣称呼就不重要。
- 可以有情感支持、照顾、长期规划，不必循恋爱模式发展。
- 当事人可以以朋友或选择的家人为关系核心。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 伴侣式关系 | 相处方式可能一样，区别在当事人是否把对方当作伴侣。 |
| QPR | 有些外观接近友谊的关系也被当事人称为 QPR。 |
| 选择的家人 | 家庭般的角色可能与伴侣身份重叠，不能强制排斥。 |

**常见误解**

- **“没叫伴侣就不够重要。”** 关系的重要性与名称不是一回事。
- **“选择的家人不能包含伴侣。”** 现实关系中的家人角色、友谊和伴侣身份可能重合。

### 社区定义

同一个人可以同时是朋友、家人般的成员和伴侣，这个分类不要求二选一。

## 亲密友谊

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `close-friendship` |
| 英文名 | Close friendship / Committed friendship（含义侧重不同） |
| 中文名 | 亲密友谊 / 承诺式友谊 |
| 别名 | — |
| 层级 | 节点 |
| 上位类 | 非伴侣式的重要关系 |
| 对应的轴 | 4A |
| 共识度 | 高 |
| 测试适配度 | A |
| 来源 | AUREA FAQ（友情的重要性、QPR 与友谊边界）；本稿并列 close 与 committed，二者并非严格同义 |
| 完成度 | 完整 |

### 通俗释义

> 一段双方都很重视、彼此信任且亲近的友谊。若双方还明确约定长期照应、维持联系或共同承担责任，也可叫承诺式友谊；它仍可以被当事人认定为朋友关系，而无须成为恋爱或伴侣。

### 核心特征

- 彼此信任、愿意深度交流或在困难中互相支持。
- 可以长期稳定，也可能有明确承诺，但不要求有正式伴侣称呼。
- 共同生活、旅行或身体亲密并不会自动把友谊变成恋爱或 QPR。
- 友谊也可以成为人生中最重要的关系之一。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| QPR | QPR 常被当事人理解为超出文化上的常规友谊，但仅凭亲密程度无法替人决定标签。 |
| 柏拉图伴侣 | 后者突出伴侣身份；亲密友谊不一定使用这一称呼。 |
| 选择的家人 | 强调家庭式归属，可以由友情发展，但未必所有好友都互称家人。 |

**常见误解**

- **“朋友不能共同生活或作承诺。”** 这些行为不专属于伴侣关系。
- **“非常亲密的朋友必须叫 QPR。”** 关系的名称和界限由当事人决定。

### 社区定义

“亲密友谊”强调关系的深度，“承诺式友谊”强调主动的承诺，这个测试把两者放在同一个选项里。AUREA 提到，一个人的 QPR 在旁人看来可能很像另一个人的友谊，界限要看当事人自己怎么认定。

## 选择的家人

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `chosen-family` |
| 英文名 | Chosen family |
| 中文名 | 选择的家人 |
| 别名 | 亲密社群网络 |
| 层级 | 节点 |
| 上位类 | 非伴侣式的重要关系 |
| 对应的轴 | 4A |
| 共识度 | 中 |
| 测试适配度 | A |
| 来源 | AUREA 英文完整术语表（Chosen family / Found family）；PFLAG National Glossary |
| 完成度 | 完整 |

### 通俗释义

> 因为情感亲近、相互支持与主动选择，一群人彼此把对方视为家人，即使没有血缘或法律亲属关系，也会在彼此生活中承担重要角色。英语称 chosen family 或 found family。

### 核心特征

- 成员彼此认可，愿意以家人般的方式相处和支持。
- 不要求血缘、婚姻、收养或其他法定亲属身份。
- 可以在陪伴、困难时照顾和日常生活中成为重要支持网络。
- 可能与友谊、QPR 或浪漫伴侣身份重叠；强调的是家庭般的归属。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 亲密友谊 | 亲密好友可能成为选择的家人，但“家人”是当事人赋予的角色，不是友谊强度等级。 |
| QPR / 浪漫伴侣 | 伴侣也可以属于选择的家人；该群体不必围绕某位伴侣。 |
| 法律家庭 | 当事人视彼此为家人，不代表自动产生法律上的亲属权利或义务。 |

**常见误解**

- **“选择的家人必须有正式组织或固定人数。”** 资料使用群体概念，但没有这种成员资格要求。
- **“只有失去原生家庭的人才能有选择的家人。”** 是否同时获得原生家庭支持，并不阻止人选择其他家人。
- **“选择的家人不能包括恋人。”** 家庭角色可以与伴侣身份同时存在。

### 社区定义

AUREA 强调相互选择与家人般的重要角色，PFLAG 强调其在 LGBTQ+ 社群中的支持意义。这种关系可能来自友谊、伴侣或其他重要联系；不能限定为“完全没有伴侣的友谊网络”。

## 以性为主的非浪漫关系

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `sexual-nonromantic` |
| 英文名 | — |
| 中文名 | 以性为主的非浪漫关系 |
| 别名 | FWB（friends with benefits，部分形式）；固定性伴侣（部分形式，非严格同义） |
| 层级 | 节点 |
| 上位类 | — |
| 对应的轴 | 4A |
| 共识度 | 中 |
| 测试适配度 | A |
| 来源 | Lehmiller（2018）Friends with Benefits；Mongeau 等（2013）FWB 关系类型研究；AUREA 的 Paramour 等相关用语。本稿描述性类别，不是固定社群术语 |
| 完成度 | 完整 |

### 通俗释义

> 一段把双方认可的性互动作为重要内容，却没有被双方定义为浪漫伴侣的关系。这个说法把几种形式放在一起，包括有友谊基础的 friends with benefits（FWB，朋友兼性伴侣），也包括未必先是朋友的固定性伴侣。

### 核心特征

- 双方愿意有性方面的互动，同时不把关系定位为浪漫伴侣。
- 可能是朋友、长期固定关系，也可能有其他相处与承诺方式。
- 是否排他、亲密程度和对未来的期待须依双方约定，不由标签自动决定。
- 关系安排不等同于是否产生对特定人的性吸引或浪漫吸引。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| FWB（朋友兼性伴侣） | 通常同时有友谊；不一定所有固定性伴侣都是朋友。 |
| 浪漫伴侣关系 | 有性行为不能单独证明两人把关系视为浪漫。 |
| QPR | QPR 也可以有性，有性不等于就属于这一类。 |
| 性吸引／性欲 | 关系安排和内在感受是不同层面。 |

**常见误解**

- **“FWB 就等于所有非恋爱性关系。”** FWB 一般还涉及友谊，更宽的类别不一定如此。
- **“非浪漫关系就没有承诺、照顾或沟通。”** 关系可以有认真协商的边界和长期安排。
- **“有性行为就一定有浪漫吸引。”** 行为与关系认定不能替代吸引体验。

### 社区定义

FWB 是其中最常听到的一种：既是朋友，又有性方面的互动，但每段关系的相处、承诺和对未来的期待都不一样。

### 通俗释义

> 在理想生活中不希望建立伴侣式关系，或者不把寻找伴侣当作自己想要的安排。一个人仍然可以看重朋友、家人、选择的家人和社群联系，也可能享受独处，而不必寻求恋爱、QPR 或其他伴侣。

### 核心特征

- 表达的是理想偏好，而不是现在是否有伴侣。
- 仍可以非常重视友谊、家庭、社群或其他联系。
- 不需要缺乏浪漫或性吸引；吸引和是否寻求伴侣是不同问题。
- 偏好可以随时间改变，不构成必须终身维持的宣告。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 当前单身 | 单身是现状；一个人可以单身而渴望伴侣。 |
| Aromantic／Aro-spec | 它描述浪漫吸引；aro-spec 者也可能想要恋爱或 QPR。 |
| 独身／不发生性行为 | 是否有伴侣与是否发生性行为不能互相推导。 |
| 未定／随缘 | 尚未决定是否寻求伴侣，不等于明确不想寻求。 |

**常见误解**

- **“没有伴侣就一定不想要伴侣。”** 现状不等于偏好。
- **“不寻求伴侣就是不需要任何人。”** 友谊与家人仍可以是重要关系。
- **“想要但暂时做不到，也算不寻求。”** 问卷问理想偏好，不问机会或当前可实现性。

### 社区定义

AUREA 收录的 nonpartnering／nonamorous 指不希望建立重要的伴侣关系。这一项只描述想要怎样的关系，不要求认同这个标签；它也不等于现在单身、没有浪漫吸引或没有性。
