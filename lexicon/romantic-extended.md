## Idemromantic

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `idemromantic` |
| 英文名 | Idemromantic |
| 中文名 | 同感浪漫倾向（社群流传） |
| 别名 | — |
| 层级 | 延伸区 |
| 上位类 | Quoiromantic |
| 对应的轴 | ① 分类方式（体验相同，只靠外部因素区分） |
| 共识度 | 低或有分歧（延伸区） |
| 测试适配度 | C |
| 来源 | AUREA；已核实；误解取自社群图文 |
| 完成度 | 完整 |

### 通俗释义

> 同感浪漫倾向（Idemromantic）指的是：浪漫吸引和柏拉图吸引的感受相同或很相似，只能靠年龄、两人合不合适、亲近程度等外部因素来区分。

### 核心特征

- 对某个人的感受，和对好朋友的亲近感很像，单看感受分不出是哪一种。
- 区分的依据主要在外部，比如对方的年龄、两人合不合适、彼此亲近到什么程度。
- 会借助社会规则或自己设定的标签来定义关系，比如“是否承诺共度一生”“是否同居或共享财务”。
- 这个标签描述的是“怎么区分”的方式，不表示对浪漫的喜欢或不喜欢。

### 体验举例

- 和一位相处很舒服的人聊天，心里的感觉和对老朋友差不多。你会靠对方是谁、你们亲近到哪一步，来判断那份感觉算不算浪漫。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Platoniromantic | 同样分不清浪漫和柏拉图，但 Platoniromantic 是感受本身分不出界线；同感浪漫是感受相同，要靠外部因素才能区分。 |
| Quoiromantic | 同感浪漫归在它底下，是它的一个分支。 |

**常见误解**

- **误解：他们只是暂时分不清喜欢的感觉。** 不对：这不是暂时的认知困惑，也不是靠经验或成长就能“学会区分”的。内在感受本来就没有可供区分的差异。
- **误解：他们对所有关系都一视同仁，没有偏好。** 不对：他们仍会有明确的偏好，选择特定的对象建立亲密关系，也可能对某些人有更强的吸引；只是不会把吸引类型分为“浪漫”或“友谊”。

## Platoniromantic

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `platoniromantic` |
| 英文名 | Platoniromantic |
| 中文名 | 柏拉图浪漫倾向（社群流传） |
| 别名 | platromantic（AUREA 词条写作 Plat(oni)romantic） |
| 层级 | 延伸区 |
| 上位类 | Quoiromantic |
| 对应的轴 | ① 分类方式（无法区分） |
| 共识度 | 低或有分歧（延伸区） |
| 测试适配度 | C |
| 来源 | AUREA；已核实；误解与体验举例取自社群图文 |
| 完成度 | 完整 |

### 通俗释义

> 柏拉图浪漫倾向（Platoniromantic）指的是：对某人的吸引，感受上无法分清是浪漫还是柏拉图。

### 核心特征

- 对某人有吸引，但没办法判断那是浪漫吸引还是柏拉图吸引。
- 不是没有感受，而是对自己来说，两类之间的界线是模糊的。
- 对非常亲密的朋友，也可能有强烈的依恋、想独占、想一起生活的感觉，但不一定会把它叫作恋爱。
- 这描述的是“分不清”本身，不表示对浪漫或友情有什么态度。

### 体验举例

- 被人问“你到底是把 ta 当朋友，还是喜欢 ta”，你想了想，心里的回答是：……都一样啊？

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Idemromantic | 同样分不清，但同感浪漫靠年龄、合适程度等外部因素能分开；Platoniromantic 是感受本身分不出界线。 |
| Quoiromantic | 与它的“分不清浪漫与柏拉图”那一支重合。 |

**常见误解**

- **误解：这不就是深厚的友谊吗？** 不对：绝大多数人能清楚分辨“好朋友的喜欢”和“想谈恋爱的喜欢”，只是强度不同。Platoniromantic 是连感受本身都分不清，是认知层面的融合，不只是“感情更深的友谊”。
- **误解：其实就是爱情，只是拒绝承认。** 不对：很多 Platoniromantic 的人根本不追求传统的浪漫关系，也不享受被追求、告白、情侣标签带来的特殊感，甚至觉得这些很奇怪或很累。

## Vexromantic

### 基本信息

| 字段 | 内容 |

| ID | `vexromantic` |
| 英文名 | Vexromantic / Vexeromantic |
| 中文名 | 迷惑浪漫倾向（社群流传） |
| 别名 | vexeromantic |
| 层级 | 延伸区 |
| 上位类 | Quoiromantic |
| 对应的轴 | ① 分类方式（无法理解这个概念） |
| 共识度 | 低或有分歧（延伸区） |
| 测试适配度 | C |
| 来源 | Orientando；已核实（社群术语资料）；误解与体验举例取自社群图文 |
| 完成度 | 完整 |

### 通俗释义

> 迷惑浪漫倾向（Vexromantic）指的是：已经知道自己属于无浪漫光谱之内，但因为看不懂“浪漫吸引”这个概念，没办法判断自己有没有、会以什么方式体验。

### 核心特征

- 对“浪漫吸引”这个概念本身感到费解。
- 因为概念看不懂，也就难以判断自己的感受属于哪一种。
- 这是“理解”上的卡住，不等于对浪漫有什么态度。

### 体验举例

- 身边的人说“心动”“想和 ta 在一起”“脸红”，你听着像外星语言，完全不知道那种感觉是什么。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Quoiromantic | 两者很接近。Quoiromantic 是“搞不懂浪漫吸引是什么，也搞不懂自己有没有”，觉得浪漫吸引的框架对自己不适用；Vexromantic 是“搞不懂浪漫吸引是什么，但知道自己肯定不是 Alloromantic，大概在 Aro 光谱中”。 |

**常见误解**

- **误解：Vexromantic 就是 Aromantic。** 不对：Vexromantic 的人大概知道自己在 Aro 光谱上，但不一定完全没有浪漫感觉，只是那份感觉太模糊、太微弱或太怪，没办法归类。严格的 Aromantic 是清楚知道自己没有浪漫吸引。
- **误解：和 Quoiromantic 完全一样。** 不对：两者很接近，细微差别见上表。

## Desinoromantic

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `desinoromantic` |
| 英文名 | Desinoromantic |
| 中文名 | 终止浪漫倾向（社群流传） |
| 别名 | — |
| 层级 | 延伸区 |
| 上位类 | Greyromantic |
| 对应的轴 | ② 频率与强度（停在"喜欢"，不会加深） |
| 共识度 | 低或有分歧（延伸区） |
| 测试适配度 | C |
| 来源 | AUREA；已核实；误解取自社群图文 |
| 完成度 | 完整 |

### 通俗释义

> 终止浪漫倾向（Desinoromantic）指的是：会对某人产生喜欢，但感受停在“喜欢”这一步，不会发展成浪漫意义上的“爱”。

### 核心特征

- 对某人有好感，想靠近、想待在一起，这份感觉是真实的。
- 吸引停在某个程度，不会再往浪漫的方向加深。
- 体验因人而异：有人偶尔会有浪漫吸引，有人则非常少有。
- 这是这个标签使用者对自己感受的描述，不用来衡量别人的爱有多深。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Greyromantic | Desinoromantic 属于它底下这一支，指的是浪漫吸引很少、很弱，并且感受具体停在“喜欢”。 |

**常见误解**

- **误解：这个词是在说爱得不够多、不够好。** 不对：它只描述自己的感受停在哪里，不用来给别人的爱排高低。
- **误解：还没遇到对的人。** 不对：这不是还没遇到，而是浪漫吸引的上限就在这里。再合适、再喜欢的人，也不会触发更深的浪漫吸引。
- **误解：肤浅、不认真的喜欢。** 不对：他们能感受到的浪漫吸引上限就只有这么多，不代表肤浅或不认真，感情同样可以很真挚。
- **误解：永远不会爱别人。** 不对：他们只是在浪漫吸引这一层停在“喜欢”，在友情、亲情等层面，仍然可以体验到深层的爱，也可以建立 QPR（酷儿柏拉图关系）。

## Apresromantic

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `apresromantic` |
| 英文名 | Apresromantic |
| 中文名 | 后置浪漫倾向（社群流传） |
| 别名 | — |
| 层级 | 延伸区 |
| 上位类 | Greyromantic |
| 对应的轴 | ③ 触发条件（需先有另一种吸引） |
| 共识度 | 低或有分歧（延伸区） |
| 测试适配度 | C |
| 来源 | AUREA；已核实；误解取自社群图文 |
| 完成度 | 完整 |

### 通俗释义

> 后置浪漫倾向（Apresromantic）指的是：浪漫吸引要在其他类型的吸引（比如柏拉图吸引、审美吸引）出现之后，才会产生。

### 核心特征

- 不会一开始就对某人产生浪漫吸引，需要先有其他类型的吸引。
- 先有的其他吸引，可能保留下来，也可能被浪漫吸引取代。
- 这个标签说的是先后顺序，不规定要等多久。
- 个人体验因人而异：有人只在特定的吸引之后才“开窍”，有人则很少被触发。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Demiromantic | 条件是要先与某人建立深厚的情感连接；Apresromantic 的条件是先有其他类型的吸引，两者的前提不同。 |

**常见误解**

- **误解：这不就是大多数人的恋爱过程吗？** 不对：大多数人的浪漫吸引通常是独立运作的，可以第一眼就觉得“我想和 TA 谈恋爱”，不需要先经过某种前置吸引。对后置浪漫者来说，这个前置条件必须存在，没有它，浪漫吸引就无法触发。

| 测试适配度 | C |

| 完成度 | 完整 |

### 通俗释义

> 初遇浪漫倾向（Coeoromantic）指的是：浪漫吸引只会在初次见面时就出现；初见时没有，之后相处也不会从无到有地产生。

### 核心特征

- 浪漫吸引只可能在初次见面时出现，甚至只是对视的那一刻；之后相处再多，也很难再“点燃”。
- 一旦在初遇时动了心，那种感觉可能很浓烈、很深刻，像谈了几年恋爱一样（不是真的谈了几年，而是情感浓度很高）。
- 对熟人反而很难产生浪漫滤镜，刚认识、甚至只见过一面的人，反而更容易让他们心动。
- 这和“相处久了才慢慢有感觉”的情况正好相反。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Demiromantic | 方向相反：Demiromantic 要先建立情感连接才会产生浪漫吸引，Coeoromantic 则是初见时就得有。 |
| Coeromantic（coe-） | 名字很像，但那是另一个词，目前只进词汇表，定义还没有定下来。不要和本词混在一起。 |

**常见误解**

- **误解：花心，或者肤浅。** 不对：这不是“花心”，也不是“肤浅”，只是浪漫的开关启动机制和大多数人不同，和人格品质无关。

## Proculromantic

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `proculromantic` |
| 英文名 | Proculromantic |
| 中文名 | 遥远浪漫倾向（社群流传） |
| 别名 | — |
| 层级 | 延伸区（对象） |
| 上位类 | Aro-spec（树中位置只作导航，不单独推出归属） |
| 对应的轴 | ⑦ 对象类型与可及性 |
| 共识度 | 低或有分歧（延伸区） |
| 测试适配度 | C |
| 来源 | Orientando；已核实（社群术语资料） |
| 完成度 | 完整 |

### 通俗释义

> 遥远浪漫倾向（Proculromantic）描述一种浪漫吸引模式：一个人只会对自己认定无法与之建立现实浪漫关系的对象产生浪漫吸引，例如虚构角色、名人，或现实中明知无法发展关系的人。重点在于本人认知中的“不可及”，而不只是物理距离远。

### 核心特征

- 浪漫吸引只出现在自己明知不可能建立现实关系的对象身上，比如名人、虚构角色，或现实中明知没有可能的人。
- 这份吸引是长期、强烈而深刻的，不只是偶尔幻想一下。
- 重点在本人心里清楚“不可能”，不只是距离远。

### 体验举例

- 喜欢一位歌手很多年，记得 ta 的每首歌、每次采访，那份心动很真实；你也清楚自己和 ta 不会有现实里的交集。
- 身边有人追求时没什么感觉，却会长期惦记一位明知不可能在一起的人。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Fictoromantic | 吸引对象是虚构角色；Proculromantic 的对象还包括现实中遥不可及的人。 |
| Adexromantic | 浪漫向往指向抽象、非特定的情境或对象；Proculromantic 可以明确喜欢一个有真实身份、十分具体的人。 |
| 远距离恋爱 | 距离描述双方相隔多远；Proculromantic 描述“明知无法建立现实浪漫关系”的对象怎样引发吸引。 |

### 社区定义

Orientando 的 Procul 词条明确使用“知道永远无法建立关系”的较宽定义，也说明早期曾有仅指“住得很远的人”的较窄用法；两种版本不能混成一个从来不变的标准。该页面还将持续、强烈的吸引与单纯幻想区分，但并未规定每个人必须持续多久、达到多大强度。

### 基本信息

| 字段 | 内容 |

| 测试适配度 | C |
| 来源 | Queer Dictionary；已核实（个人整理）；独立造词来源待核 |
| 完成度 | 完整 |

### 通俗释义

> 抽象浪漫倾向（Adexromantic）在现有社群整理中的意思是：一个人会对非真实、非特定的对象或抽象浪漫情境产生浪漫方面的向往、欲望或类似吸引的体验，但面对现实中真实而具体的个人时，并不产生同样的浪漫欲望或吸引。

### 核心特征

- 在幻想里可以想象浪漫场景、约会、亲密互动或情感连接，感受甚至会非常强烈；这些想象指向模糊、非特定或抽象的对象。
- 幻想里的对象可能缺少明确的样貌、身份和现实经历。把现实生活中的某个具体人物放进相同情境时，原本的浪漫感受可能迅速淡化或变味。
- 内心可以拥有丰富的浪漫想象与愿望，而面对现实中真实、具体的人时，浪漫吸引呈现出另一种样貌。
- 喜欢想象中的浪漫关系、享受故事与幻想的情绪，并且清楚感受到这种体验与面对现实人物时的差异。

### 体验举例

- 睡前会想象和“一个人”在雨天散步、一起做饭，心里很暖；那个人没有脸、没有名字，换成身边认识的谁，这份向往就不见了。
- 享受恋爱故事和亲密情节，同时对现实中具体的人很少产生同样的浪漫心动。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Aegoromantic | 关注自己是否参与幻想中的浪漫场景；Adexromantic 更关注幻想中的抽象对象与现实具体人物带来的体验差异。 |
| Fictoromantic | 浪漫吸引可以明确指向某个有名字、有形象的虚构角色；Adexromantic 的对象通常更抽象、模糊。 |
| Proculromantic | 可以喜欢身份明确却遥不可及的人；Adexromantic 的浪漫体验更多发生在非特定对象和抽象情境里。 |

### 社区定义

Queer Dictionary 收录了这个词，和性侧的 adexsexual 写在同一条里。有人这样形容这种感觉：浪漫的想象本身很吸引人，可一旦把现实中某个具体的人代进去，感觉就变了味。

> 虚拟浪漫倾向（Fictoromantic）指对虚构角色产生浪漫吸引的人；有人的浪漫吸引主要或仅指向虚构角色，也有人同时会被现实人物吸引。只有当其对现实人物很少或没有浪漫吸引等情形与本人认同相符时，才可能同时把它视为 aro-spec 身份。

### 核心特征

- 浪漫吸引主要或只指向小说、动漫、游戏、影视等作品中的虚构角色。对角色可能有持续的心动、思念、爱慕与深刻的情感联结。
- 有些人现实中也会欣赏他人的外貌、性格，与朋友建立亲密感情；但强烈的浪漫心动主要出现在面对虚构角色时。
- 与现实中的朋友、家人或重要伙伴仍可以建立深厚关系，包括亲密友谊与酷儿柏拉图关系（QPR）。
- 虚构角色可能成为一个人情感生活的重要部分，喜欢角色的方式也会因作品、个人经历与关系想象而变化。

### 体验举例

- 反复想念某个虚构角色，期待再次在作品中见到对方，或想象与角色约会、相伴。
- 现实生活中重视友情和亲密陪伴，自己的浪漫情感却更多投注于虚构角色。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Proculromantic | 关注遥不可及对象带来的浪漫吸引；Fictoromantic 关注吸引对象的虚构性质。 |
| Adexromantic | 关注抽象、非特定的浪漫幻想；Fictoromantic 可以指向姓名、性格、经历和形象都很鲜明的具体角色。 |
| 对作品或角色的欣赏 | 欣赏角色的剧情、设计与性格，和对角色产生浪漫爱慕，是两种可以并存的体验。 |

### 社区定义

AUREA 的身份术语表把它定义为对虚构角色产生浪漫吸引。有的人几乎不对现实中的人心动，这时也可能认同 aro-spec；也有人对虚构角色和现实中的人都会心动。

### 通俗释义

> 自我浪漫倾向（Autoromantic）指的是：浪漫方面的吸引，对象是自己。

### 核心特征

- 浪漫方面的吸引，指向的对象是自己。
- 可以与对他人的吸引并存。
- 喜欢给自己制造浪漫氛围，比如一个人看电影、散步、吃烛光晚餐，庆祝个人纪念日，想象与自己共度浪漫时光。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| 自我伴侣（self-partnered） | 指的是一种关系做法：把自己当作伴侣来对待、经营。Autoromantic 描述的是吸引的对象，自我伴侣描述的是相处的方式。 |

**常见误解**

- **误解：自我浪漫就是自恋。** 不对：这个标签只说吸引的指向，不评价性格。

### 核心特征

- 想要成为别人浪漫喜欢、追求或爱慕的对象。被认真地喜欢、收到浪漫表达，本身就可能带来快乐和满足。

### 体验举例

- 收到告白、情书或浪漫惊喜时感到高兴；想到要以同样的浪漫方式回应对方，却发现自己的感受停留在另一种亲近之中。

### 概念边界

**相似的标签**

| 标签 | 区别 |

这个词的说法来自 aro.ju.mp，重点是：希望别人对自己有浪漫吸引，自己却回应不了同样的吸引。被人喜欢时，有人会觉得别扭、空落，或想把这件事淡化，也有人没有这些感受。

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `morphoromantic` |
| 英文名 | Morphoromantic |
| 中文名 | 蝶浪漫倾向（社群流传） |
| 别名 | — |
| 层级 | 延伸区（成分） |
| 上位类 | Aro-spec |
| 对应的轴 | ⑨ 成分与契合感（只有反应或表现） |
| 共识度 | 低或有分歧（延伸区） |
| 测试适配度 | C |
| 来源 | 社群讨论、Tumgik 转载；已核实（转述用法）；原始造词出处待核 |
| 完成度 | 完整 |

### 通俗释义

> 蝶浪漫倾向（Morphoromantic）描述一个人并不体验浪漫吸引，却会出现通常被别人视为“心动”或“喜欢上谁”的反应、表现或感受，例如紧张、脸红、心跳变化、想更靠近对方等。本人并不因此把这些反应认作对该对象的浪漫吸引。

### 核心特征

- 本人没有浪漫吸引的体验，却可能出现通常被人们和浪漫心动联系在一起的身体或情绪反应。
- 这些生理和情绪反应出现时，感觉可以很鲜明；但本人对它们的理解更接近生理兴奋、审美吸引、感官吸引或其他情感体验。
- 反应可能随着遇见的人、环境和当时的情绪出现或消退，而本人对自己浪漫吸引模式的理解仍然相对稳定。

### 体验举例

- 看到某个人时忽然脸红、心跳很快，甚至想再多看一眼；过后回想，自己感受到的是兴奋、欣赏或亲近的愿望。
- 和一位新同事第一次单独吃饭，一直紧张、手心出汗；回家想了想，发现自己并不想和对方发展成恋人。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Pseudoromantic | 关注其他吸引带来的类似浪漫感受；Morphoromantic 更突出浪漫吸引缺席时仍会出现典型的心动反应。 |
| Acriromantic | 已经产生浪漫吸引，同时觉得这份吸引不自然；Morphoromantic 描述有类似心动反应、却没有相应浪漫吸引的体验。 |
| 审美或感官吸引 | 欣赏一个人的外貌、想与对方贴近，都可能伴随紧张、兴奋或心跳变化。 |

### 社区定义

社群里常把这些反应叫作浪漫吸引的“症状”，这是比喻，不是医学上的症状。紧张、脸红、心跳加快只是例子，每个人出现的反应不一样。

### 通俗释义

> 伪浪漫倾向（Pseudoromantic）是 aro-spec 社群中的微标签：一个人体验到审美、感官、性、柏拉图或其他**非浪漫吸引**，这些吸引与浪漫吸引十分相似、相邻，甚至引发类似浪漫的感受。也有使用者本身可能体验某种浪漫吸引，但它被另一种强烈吸引盖过，因此难以辨认。

### 核心特征

- 审美、感官、性或情感等吸引可能引发类似浪漫心动的感受：看见对方会兴奋、心跳加速，想象与对方相处，甚至产生强烈的情感波动。
- 有些人会被爱情故事、电影或虚构角色触动，沉浸在浪漫幻想中；回到现实生活，面对具体的人时，建立浪漫关系的冲动却很少出现。
- 情绪上的心动与浪漫行为的愿望可能分离。即使经历兴奋、幻想和亲近感，也很少自然地想要表白、约会或发展恋爱。
- 社群造词讨论还提到 Sensromantic（感官吸引主导的类似浪漫体验）与 Emovromantic（情感吸引主导的类似浪漫体验）等细分说法。

### 体验举例

- 欣赏一个人的外表、想拥抱或贴近对方，随之产生“好像恋爱了”的兴奋；认真设想恋爱相处时，感受又更接近审美、感官或情感上的亲近。
- 对某个故事里的恋爱情节非常投入，心里也会有强烈的浪漫波动；现实中的关系愿望则以友情、QPR 或其他亲密方式为主。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Morphoromantic | 侧重浪漫吸引缺席时出现心跳、脸红等典型反应；Pseudoromantic 侧重其他类型的吸引与浪漫吸引相似、接近或相互遮盖。 |
| Quoiromantic | 侧重一个人怎样理解、区分浪漫吸引与其他吸引；Pseudoromantic 描述各种吸引在感受上的相似和交叠。 |
| Sensromantic / Emovromantic | 造词讨论里的两个细分方向，分别突出身体感官体验与情感吸引带来的类似浪漫感受。 |

### 社区定义

这个词出自 2022 年 Reddit 上的一篇造词帖。造词的人还提了两个更细的说法：sensromantic（偏身体感官）和 emovromantic（偏情感吸引）。

### 核心特征

- 确实会对某个人产生浪漫吸引，也会感受到喜欢、心动或想与对方更亲近；与此同时，这份吸引让自己感到明显的陌生、违和或不自在。

### 体验举例

- 喜欢上某个人时会心跳、期待见面，随即冒出“这种感觉怎么会发生在我身上”的强烈别扭感。
- 即使对方很好、相处也愉快，自己仍觉得浪漫心动这件事和自我认知格格不入。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|

| Orchidromantic | 体验浪漫吸引，但倾向于不进入浪漫关系；Acriromantic 的侧重点是浪漫吸引发生时的主观违和。 |
| 面对具体关系的犹豫 | 顾虑可能围绕相处、承诺和未来生活；Acriromantic 的违和感直接围绕浪漫吸引的产生与存在。 |

这个词出自 mogaiheaven 整理的一组 acri- 词，同一组里还有性、感官、审美等吸引对应的 acri- 说法。

| 标签 | 区别 |
|---|---|
| Aromantic | 只说很少或没有浪漫吸引，不谈对浪漫的感受；Apothiromantic 额外包括排斥。 |

**常见误解**

- **误解：只要是 aromantic，就一定排斥浪漫。** 不对：Aromantic 没有提到排斥，有没有排斥是另外一回事。
- **误解：只是受过情伤，或原生家庭不幸。** 不对：这是一种取向认同，不是心理创伤的后遗症。创伤可能导致排斥，但很多人从未受过伤，只是单纯地对浪漫无感且排斥。
- **误解：只是还没遇到对的人。** 不对：对这些人来说，不存在“对的人”能打开浪漫开关，因为那个开关本身就不存在。强行推销浪漫，只会让他们感到痛苦。
- **误解：讨厌所有情侣。** 不对：因人而异。有人排斥所有浪漫相关的概念，也有人会祝福身边的情侣朋友，只是希望大家尊重他们的边界。
- **误解：讨厌亲密行为，就是 Apothiromantic。** 不对：排斥的是浪漫，不是亲密。如果只是不喜欢肢体接触，但仍然会心动、想谈恋爱，那更可能是个人边界感较强。

### 通俗释义

> 某浪漫倾向（Alicoromantic）指的是：知道自己属于无浪漫光谱之内，但现有的标签都不太贴切，或者还不知道哪个最合适。

### 核心特征

- 确定自己属于浪漫方面较少或没有的一类。
- 觉得已有的名称都不完全符合自己。
- 这个词不说明吸引的方式，只表示自己在这个范围之内。是否使用，由本人决定。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Aromantic | 有具体定义的标签；Alicoromantic 不说明吸引的方式，只是一个让人先归位的说法。 |
| Quoiromantic | 有部分重叠。Quoiromantic 侧重难以分清浪漫吸引和友情等其他吸引，或觉得“浪漫吸引”的概念对自己不适用；Alicoromantic 侧重知道自己在无浪漫谱系上，却没有一个细分标签能对上。 |

**常见误解**

- **误解：只是还没找到合适标签的过渡阶段。** 不对：有人以为它只是暂时用的，等探索久了就会找到更精确的词。对很多人来说，这本身就是一个稳定的身份，意思是“我就是无法被现有标签完全定义”。
- **误解：一定不喜欢任何浪漫关系。** 不对：浪漫取向不等于行为。有些人仍然享受浪漫关系，或对浪漫元素感兴趣，只是吸引方式不符合典型定义。

### 社区定义

有人把它当成临时标签，等找到更合适的再换；也有人觉得它本身就是最贴切的长期身份。

## Orchidromantic

### 基本信息

| 字段 | 内容 |
|---|---|
| ID | `orchidromantic` |
| 英文名 | Orchidromantic |
| 中文名 | 兰花浪漫倾向（社群流传） |
| 别名 | — |

| 上位类 | Aro-spec |
| 对应的轴 | 1C 浪漫关系意愿（有吸引，但不想要关系） |
| 共识度 | 低或有分歧（延伸区） |
| 测试适配度 | C |
| 来源 | 社群图文（未另找到出处） |
| 完成度 | 完整 |

### 通俗释义

> 兰花浪漫倾向（Orchidromantic）指的是：能感受到浪漫吸引（会心动、会 Crush），但主观上不想或不渴望把它发展成浪漫关系的体验。简单来说，就是“我喜欢你，但我不想和你谈恋爱”。

### 核心特征

- 会对他人在浪漫层面上产生好感、心动或迷恋（Crush）。
- 尽管有这种感觉，却不想把它转化为实际的恋爱关系，比如约会、确立恋爱关系。
- 这份感觉对自己来说本身就够了，不一定需要现实中的互动，满足于在脑海中幻想。
- 可能更重视友情、亲情或酷儿柏拉图关系（QPR），而不是浪漫恋爱关系。

### 体验举例

- 心仪一位朋友，常会想象两人在一起的样子，但从没想过真的要约会。

### 概念边界

**相似的标签**

| 标签 | 区别 |
|---|---|
| Cupioromantic | 方向相反：cupio 想要浪漫关系，但很少有浪漫吸引；orchid 有浪漫吸引，却不想发展成关系 |
| Aromantic | aromantic 很少或从不有浪漫吸引；orchid 有吸引，只是不想行动 |
| 不寻求伴侣式关系（主动单身） | 同样不想恋爱，但主动单身讲的是意愿，不限于有没有吸引；orchid 特指有吸引却不想行动 |

**常见误解**

- **误解：这是欲擒故纵的渣人。** 不对：“渣”是玩弄感情，兰花浪漫倾向者是诚实地面对自己。他们是真的享受心动，也是真的不想进入关系，就像很喜欢猫，但知道自己不想铲屎、不想养，所以选择“云吸猫”。
- **误解：他们是因为受过伤，或是恐惧、回避型依恋。** 不对：心理创伤是需要治愈的痛苦，而兰花浪漫倾向是一种舒适的取向。他们不谈恋爱不是因为“害怕受伤”，而是因为“更喜欢单身”、“这种距离感刚刚好”，或单纯对恋爱关系不感兴趣；他们对此感到快乐，而不是焦虑。

### 社区定义

原因因人而异，可能包括：觉得维持一段浪漫关系太麻烦或压力太大；更享受单身或独立性；满足于仅仅在脑海中幻想，或只是感受到这种吸引力本身就足够了；更重视友情、亲情或酷儿柏拉图关系（QPR）。
