# Unfixed 🌌

[简体中文](README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | [日本語](README.ja.md)

一份关于**吸引、感受与亲密关系**的互动式自我探索手册。

喜欢一个人，一定想谈恋爱吗？想和谁亲近、分享生活，却说不清那是友情、浪漫的喜欢，还是另一种感受？也许你更在意彼此如何相处，而不是关系应该叫什么。

Unfixed 从五个方向出发，邀请你认识自己的感受，也看看世界上还有哪些描述吸引与关系的词。你可以跟着问题探索，也可以直接翻阅名词库。

**[在线体验 Unfixed](https://unfixed.lumenw.withtoge.us)**（国内可直接打开） · [备用地址1](https://unfixed.lumenw.workers.dev)[备用地址2](https://xiaoyou5602.github.io/Unfixed)

## 探索什么

- **浪漫吸引**：浪漫意义上的喜欢如何出现，又会怎样变化。
- **性吸引**：区分性吸引、性欲、对性的态度和性关系意愿。
- **其他吸引**：柏拉图吸引、感官吸引、审美吸引、别样吸引等。
- **关系偏好**：想建立怎样的关系，期待哪些具体的亲密与陪伴。
- **关系结构与理念**：怎样看待排他性、关系数量、优先级与社会默认的关系路径。

## 名词从哪里来

术语参考 AUREA、AVEN、LGBTQIA Wiki 等社群资料，以及其他公开讨论、原始概念文章和相关研究文献。收录范围包括 aro/ace 光谱、各种吸引类型、关系形态及多元关系理念。

部分微标签的定义和中文译名仍有分歧，名词库也还在持续补充与审校。具体来源、译名和待核项目记录在 [来源附录](appendix-names-and-sources.md)。

## 怎么理解结果

结果会按不同维度呈现可能与你的体验接近的词，供你继续阅读与比较。你可以采用某个标签、暂时保留疑问，也可以完全不用标签。如果浪漫吸引与性吸引难以分开，还有整体作答的选择。

题目和结果匹配规则由项目自行设计，目前尚未经过心理测量学效度验证。这是一份自我探索手册。

## 怎么用

不按年龄分流，也不询问性经历；与性有关的题目可以跳过。任何对自身体验和关系观念好奇的人都可以参与，无需先了解相关术语。

本地版的逐题作答记录保存在浏览器里。

项目仍在测试和完善中，题目、结果与名词库都欢迎大家反馈。
