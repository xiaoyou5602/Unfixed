# Unfixed 🌌

[简体中文](README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | [日本語](README.ja.md)

一份關於**吸引、感受與親密關係**的互動式自我探索手冊。

喜歡上一個人，就一定會想談戀愛嗎？想和某個人親近、分享生活，卻說不清那是友情、浪漫的喜歡，還是另一種感受？也許你更在意彼此如何相處，而不是這段關係應該叫什麼。

Unfixed 從五個方向出發，邀請你認識自己的感受，也看看世界上還有哪些描述吸引與關係的詞彙。你可以跟著問題探索，也可以直接翻閱詞彙庫。

**[線上體驗 Unfixed](https://unfixed.lumenw.withtoge.us)**（中國大陸可直接開啟）· [備用網址](https://unfixed.lumenw.workers.dev)

> 目前互動測試**僅提供簡體中文版本**。

## 探索什麼

- **浪漫吸引**：浪漫意義上的喜歡如何出現，又會怎樣變化。
- **性吸引**：區分性吸引、性慾、對性的態度，以及參與性關係的意願。
- **其他吸引**：柏拉圖式吸引、感官吸引、美感吸引、別樣吸引（alterous attraction）等。
- **關係偏好**：想建立怎樣的關係，期待哪些具體的親密與陪伴。
- **關係結構與理念**：如何看待排他性、關係數量、優先順序與社會預設的關係路徑。

## 詞彙從哪裡來

術語參考 AUREA、AVEN、LGBTQIA Wiki 等社群資料，以及其他公開討論、原始概念文章和相關研究文獻。收錄範圍包括 aro/ace 光譜、各種吸引類型、關係形式及多元關係理念。

部分微標籤的定義和中文譯名仍有分歧，詞彙庫也還在持續補充與審校。具體來源、譯名和待查核項目記錄在[來源附錄](appendix-names-and-sources.md)。

## 怎麼理解結果

結果會依不同面向呈現可能與你的體驗接近的詞彙，供你繼續閱讀與比較。你可以採用某個標籤、暫時保留疑問，也可以完全不用標籤。如果浪漫吸引與性吸引難以分開，也可以選擇整體作答。

題目和結果配對規則由本專案自行設計，目前**尚未經過心理計量學的效度驗證**。這是一份自我探索手冊。

## 怎麼使用

不會依年齡分流，也不詢問性經驗；與性有關的題目可以跳過。任何對自身體驗和關係觀念感到好奇的人都可以參與，無須先了解相關術語。

本機版本的逐題作答紀錄會保存在瀏覽器中。

專案仍在測試和完善中，歡迎大家對題目、結果與詞彙庫提供回饋。
